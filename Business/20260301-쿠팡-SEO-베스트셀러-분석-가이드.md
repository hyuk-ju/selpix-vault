# 쿠팡 SEO + 베스트셀러 분석 가이드

> 위탁판매자가 광고 없이 오가닉 매출을 올리기 위한 실전 가이드

## 1. 쿠팡 검색 알고리즘 구조

### 3가지 노출 채널

```
검색 노출 ← 판매 데이터 기반 (가장 중요)
카테고리 노출 ← 판매량 + 리뷰 중심
메인 노출 ← 로켓배송 + 기획전 연계
```

### 검색 순위 결정 요소 (가중치 순)

| 순위 | 요소 | 설명 |
|------|------|------|
| 1 | **전환율 (CVR)** | 클릭 → 구매 비율. 가장 강력한 시그널 |
| 2 | **클릭률 (CTR)** | 검색 결과에서 클릭된 비율 → 썸네일/상품명 품질 |
| 3 | **판매량** | 누적 판매 + 최근 판매 추세 |
| 4 | **리뷰 수/평점** | 리뷰 10개 이상부터 순위 영향 본격화 |
| 5 | **배송 방식** | 로켓배송 > 로켓그로스(판매자로켓) > 판매자배송 |
| 6 | **판매자 점수** | 정시출고, 정시배송, 주문이행, 24h 응답 |
| 7 | **가격 경쟁력** | 단위당 판매가 기준 |

### 2024 하반기 이후 변화

- **광고비 < 실제 소비자 행동** (찜수 증가율, 실구매 전환율 강화)
- 검색 → 필터 → 탐색 → 체류 → 후기 전체 경로 평가
- 단순 "구매 숫자"만 보지 않음

### 신규 상품 부스팅

공식적인 "허니문 기간"은 없지만:
- 등록 후 **수시간~1일** 시스템 반영 시간 필요
- **초기 리뷰 빠르게 확보**하면 순위 상승에 결정적
- 첫 5일~2주의 전환율이 장기 순위를 좌우

## 2. 상품명 최적화

### 구조

```
[핵심키워드] [보조키워드] [속성] [용도/타겟]
```

### 규칙

| 규칙 | 설명 |
|------|------|
| **앞 40자가 핵심** | 쿠팡 검색 가중치가 앞쪽에 집중 |
| 총 길이 | 100자 이내 권장 |
| 핵심 키워드 | 반드시 상품명 맨 앞에 |
| 보조 키워드 | 동의어, 관련어 자연스럽게 |
| 브랜드명 | 인지도 없으면 뒤로 (위탁판매자는 생략 가능) |

### 예시

```
❌ 나쁜 예: ABC스토어 고급 프리미엄 멀티 3단 접이식 자동 우산
  → 브랜드가 앞에, 핵심키워드(우산)가 뒤에

✅ 좋은 예: 3단 자동우산 접이식 암막 양산 자외선차단 UV 경량 우양산
  → "자동우산" "접이식" "양산" 핵심키워드가 앞에
```

### 쿠팡 자동완성 활용법

1. 쿠팡 검색창에 핵심 키워드 입력
2. 자동완성 추천어 = 실제 사용자 검색어
3. 이 키워드들을 상품명 + 검색태그에 활용
4. 예: "수납" 입력 → "수납박스", "수납정리함", "수납바구니" 등

## 3. 검색 태그 (최대 20개)

### 전략

```
태그 1~5:  핵심 키워드 (메인 검색어)
태그 6~10: 동의어/유의어
태그 11~15: 롱테일 키워드 (구체적 용도)
태그 16~20: 관련 검색어, 시즌 키워드
```

### 예시 (수납박스)

```
1. 수납박스        6. 리빙박스        11. 옷정리함        16. 이사용품
2. 정리함          7. 보관함          12. 장난감정리      17. 대용량수납
3. 수납용품        8. 플라스틱박스    13. 신발정리함      18. 접이식수납
4. 수납정리함      9. 투명수납        14. 침대밑수납      19. 원룸정리
5. 정리수납        10. 다용도수납     15. 옷장정리        20. 이불수납
```

### 주의

- 상품과 무관한 키워드 → 스팸 판정 → 노출 제한
- 경쟁사 브랜드명 → 정책 위반
- 과도한 키워드 나열 → 역효과

## 4. 상세페이지 최적화

### 이미지 (가장 중요)

| 항목 | 기준 | 효과 |
|------|------|------|
| 대표 이미지 | 1000×1000px 이상, 흰 배경 | **CTR 139% 상승** |
| 이미지 수 | 최소 5장 | 전환율 향상 |
| 해상도 | 고해상도 (쿠팡 가이드 준수) | 노출 제한 방지 |
| 모바일 최적화 | 세로형 이미지 | 모바일 구매 비율 70%+ |

### 불릿포인트 (상품 특징)

```
✅ 3~5개 핵심 특징
✅ 구체적 수치 포함 ("30L 대용량", "500g 초경량")
✅ 고객 혜택 중심 ("넉넉한 수납공간으로 정리 끝!")
❌ 모호한 표현 ("고급 소재", "프리미엄 품질")
```

### 상세 설명 HTML

- 이미지 중심 구성 (텍스트만 있으면 이탈률↑)
- 사이즈/재질 상세 표기 → 반품률 감소
- 도매매 기본 상세페이지를 그대로 쓰지 말고 **편집/보완**

## 5. 아이템위너 — 위탁판매의 핵심 장벽

### 아이템위너란?

동일 상품을 여러 판매자가 팔 때, **1명만 대표 노출**되는 시스템.

### 선정 기준

```
1. 판매가 (낮을수록 유리)
2. 단위당 판매가격 (낮을수록)
3. 배송비 (낮을수록)
4. 재고 현황 (충분할수록)
5. 출고소요기간 (짧을수록)
6. 판매자점수 (높을수록)
```

### 위탁판매자의 아이템위너 분리 전략

같은 도매매 상품을 다른 셀러와 다르게 보이게:

1. **썸네일 차별화** — 도매매 기본 이미지 대신 직접 편집
2. **세트/번들 구성** — 수영가방 + 방수파우치 세트
3. **옵션명 변경** — 도매매 기본 옵션명을 나만의 이름으로
4. **상세페이지 독자 구성** — 복붙하지 않기
5. **브랜드 등록** — 고유 브랜드명 등록 (상표권까지는 불필요)

## 6. 리뷰 확보 전략

### 합법적 방법 3가지

| 방법 | 설명 | 위험도 |
|------|------|--------|
| 포토리뷰 이벤트 | 상세페이지에 "리뷰 작성 시 쿠폰" 안내 | 낮음 |
| 체험단 | 마이크로 인플루언서에게 상품 제공 → 솔직 리뷰 | 보통 |
| 품질 개선 | 정성 포장, 빠른 CS → 자발적 리뷰 유도 | 없음 |

### 주의

- **배송 내 안내카드**: 쿠팡 정책상 리뷰 대가 제공은 위반 가능성
- **가구매/어뷰징**: 계정 영구 정지 위험
- **리뷰 10개** 이상부터 오가닉 노출 급증

## 7. 베스트셀러 분석 방법론

### 분석 도구

| 도구 | 기능 | 비용 |
|------|------|------|
| **셀러라이프** | 쿠팡 키워드/카테고리 분석, 매출 추정, 포화도 | 유료 |
| **아이템스카우트** | 키워드 검색량, 경쟁률, 경쟁사 매출 추정 | 무료+유료 |
| **쿠파일럿** | 쿠팡 데이터 분석기 | 유료 |
| **쿠팡 자동완성** | 실시간 검색어 트렌드 | 무료 |

### 베스트셀러 카피 프레임워크

```
1. 키워드 선정
   → 네이버 DataLab + 쿠팡 자동완성으로 수요 확인
   → 아이템스카우트로 검색량 vs 경쟁 비교

2. 베스트셀러 찾기
   → 쿠팡에서 해당 키워드 검색
   → 1페이지 상위 5개 분석
   → 셀러라이프로 예상 매출/판매량 확인

3. 분석 항목 (카피할 것)
   ├─ 상품명 구조 (키워드 배치)
   ├─ 가격대 (최저가? 중간가?)
   ├─ 썸네일 스타일 (배경, 각도, 텍스트)
   ├─ 검색태그 (무엇을 넣었나)
   ├─ 상세페이지 구성 (이미지 수, 정보 배치)
   └─ 리뷰 키워드 (고객이 무엇을 칭찬하는지)

4. 차별화 (카피하지 말 것)
   ├─ 독자적 썸네일 이미지
   ├─ 세트/번들 구성
   ├─ 더 나은 상세 설명
   └─ 가격 5~10% 경쟁력
```

| 7NC 모니터받침대 듀얼 높은 와이드 모니터선반 | 키워드+유형+크기+동의어 |

**경쟁 키워드**: 높이조절, 듀얼, 와이드, 원목, 아크릴, 서랍형, 모니터선반

### 상품명 구성 공식 (위탁판매자용)

```
[서브키워드1] [서브키워드2] [메인키워드] [규격/용량]
```

- 브랜드 인지도 없으면 생략 또는 맨 뒤
- 앞 40자에 핵심 키워드 집중 (모바일 35~45자 노출)
- 100자 이내 (2024.03~ 변경)
- 금지어 절대 불포함 (최저가/특가/무료배송/신상 등)
