# Selpix 틈새 공략 + 소액 광고 병행 전략

## 목표
대형 브랜드와 정면승부하지 않고,
수요는 존재하지만 독점되지 않은 마이크로 세그먼트를 공략하여
소액 광고 기반으로 안정적인 수익 구조를 만든다.

---

# 1. 전체 전략 구조

## 전략 흐름

1. 인기 대카테고리 탐색
2. 광고 구조 분석
3. 브랜드 독점도 분석
4. 틈새 세그먼트 도출
5. 도매 후보 매칭
6. 마진 계산
7. 소액 광고 테스트
8. 데이터 기반 확장 or 철수

---

# 2. 카테고리 분석 단계

## 2.1 1차: 인기 카테고리 선정

### 수집 데이터
- 상위 50개 상품
- 광고 여부
- 리뷰 수
- 판매가
- 브랜드명

### 분석 지표

| 항목 | 설명 |
|------|------|
| 평균 리뷰 수 | 수요 강도 |
| 리뷰 증가 속도 | 회전율 |
| 광고 비율 | 시장 경쟁 구조 |
| 가격 평균 | 마진 가능성 |

---

## 2.2 광고 구조 분석

### 확인할 것

1. 상위 20개 중 광고 상품 개수
2. 광고 브랜드 다양성
3. 광고 상품 리뷰 분포
4. 자연 노출 상품 리뷰 분포

### 해석 기준

- 광고 많음 + 브랜드 다양 → 진입 가능성 있음
- 광고 많음 + 2~3 브랜드 독점 → 회피
- 광고 적음 + 리뷰 낮음 → 수요 부족 가능성

---

# 3. 틈새 판단 점수 모델

틈새 점수 =
(리뷰 분산도 x 0.3) + (브랜드 분산도 x 0.3) + (가격 스펙트럼 x 0.2) - (상위 독점도 x 0.2)

### 설명

- 리뷰 분산도: 상위 20개 리뷰 편차
- 브랜드 분산도: 브랜드 개수
- 가격 스펙트럼: 최저~최고가 범위
- 상위 독점도: 1~3위 점유 집중도

---

# 4. 마이크로 세그먼트 추출

## 예시

- BAD: 수영 가방
- GOOD: 초등 방수 수영가방 20L 무자국

### 추출 방법

1. 자동완성 키워드 수집
2. 상위 상품 공통 키워드 추출
3. 반복 등장 기능어 추출
4. 타겟 연령/성별/용도 세분화

---

# 5. 도매 매칭 전략

## 전체 벡터화 금지

도매 전체 벡터화 X

### 절차

1. 세그먼트 기준 키워드 필터
2. 가격대 필터
3. 최소 판매 이력 필터
4. 후보만 벡터화
5. 상위 상품 특징 벡터와 유사도 비교

---

# 6. 마진 계산 구조

## 기본 가정

- 판매가
- 도매가
- 쿠팡 수수료
- 배송비
- 광고비 (ROAS 500% 가정)
- 기타 비용

## 순이익 계산

순이익 = 판매가 - 도매가 - 수수료 - 배송비 - 광고비

---

# 7. 소액 광고 전략

## 7.1 테스트 기준

- 일 광고비: 5,000 ~ 20,000원
- 테스트 기간: 3~5일
- 목표 ROAS: 300% 이상

---

## 7.2 광고 구조

1. 자동 키워드 광고
2. 세그먼트 키워드 집중
3. 브랜드 키워드 배제
4. 가격 경쟁력 유지

---

## 7.3 데이터 판단 기준

| 지표 | 판단 |
|------|------|
| 클릭률 낮음 | 상세페이지 문제 |
| 클릭률 높음, 전환 낮음 | 상품/가격 문제 |
| ROAS 낮음 | 세그먼트 실패 |

---

# 8. 철수 기준

- 5일 연속 ROAS 200% 미만
- 경쟁 브랜드 광고 단가 급등
- 리뷰 확보 실패
- 마진 10% 미만 유지

---

# 9. 확장 기준

- ROAS 400% 이상 7일 유지
- 리뷰 자연 유입 시작
- 광고 단가 안정화
- 동일 세그먼트 파생 상품 가능

---

# 10. Selpix 자동화 확장 방향

## 자동화 요소

- 카테고리 점수 리포트 자동 생성
- 브랜드 독점도 자동 계산
- 틈새 점수 자동 산출
- 마진 계산 자동화
- 광고 효율 대시보드

---

# 최종 결론

틈새 공략은
"경쟁이 없는 시장"을 찾는 것이 아니라
"경쟁은 있지만 독점되지 않은 세그먼트"를 찾는 것이다.

Selpix는
키워드 생성기가 아니라
시장 구조 분석기로 진화해야 한다.
