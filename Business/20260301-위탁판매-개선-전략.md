# 위탁판매 개선 전략

> 사입 없이 위탁판매(드롭쉬핑)만으로 순이익을 월 29만원 → 60만원+ 끌어올리는 전략

## 현재 문제 요약

| 항목 | 현재 | 목표 |
|------|------|------|
| 월 순이익 | 29만원 | 60만원+ |
| 광고비/매출 | 23.5% | 15% 이하 |
| 오가닉 비율 | 16.6% | 30%+ |
| 사계절 매출 비중 | 18% | 50%+ |
| 매출 발생 상품 | 소수 | 20개+ |

## 전략 1: 도매매로 전환 — 위탁판매 인프라 확보

### 도매꾹 vs 도매매 핵심 차이

| 비교 | 도매꾹 | 도매매 |
|------|--------|--------|
| **운영 방식** | 사입 전용 (내가 직접 구매→배송) | **위탁판매 가능** (공급사가 직배송) |
| **배송** | 주문마다 내가 배송비 부담 (2,700원) | 공급사가 고객에게 직배송 |
| **재고 리스크** | 없음 (건별 구매) | 없음 (위탁) |
| **마진율** | 15~25% (배송비 포함) | 20~35% (배송비 공급사 부담) |
| **대량등록** | 수동 or 자체 스크립트 | **스피드고** 무료 대량등록 |
| **쿠팡 연동** | 자체 API 구현 필요 | **스피드고2.0** 쿠팡 자동 연동 |
| **상품 수** | 제한적 | 500만개+ |

### 도매매 전환 시 예상 효과

현재 도매꾹 드롭쉬핑의 원가율: **37~47%** (배송비 포함)
도매매 위탁 전환 시 원가율: **25~35%** (배송비 공급사 부담)

→ **매출 대비 원가 7~12%p 절감** 가능

### 도매매 핵심 기능

- **스피드고**: 무료 대량등록 솔루션 (쿠팡/G마켓/옥션 지원)
- **해외직배송상품관**: 해외 상품도 위탁 가능
- **초보자 무료 교육**: 셀러 교육 프로그램 제공
- **복수계정 관리**: 스피드고2.0으로 여러 쿠팡 계정 관리

### 주의사항

- 2025년 3월부터 쿠팡 위탁판매 정책 변화 (일부 공급사 중단)
- 반품 처리가 가장 까다로운 부분 — 공급처별 반품 정책 사전 확인 필수
- 다수 판매자 이용 → **최저가 경쟁 심화** 가능성

## 전략 2: 도매 사이트 다변화 — 상품 소싱처 확대

### 추천 플랫폼 5개

| 순위 | 사이트 | 강점 | 위탁 가능 | 쿠팡 연동 |
|------|--------|------|----------|----------|
| 1 | **도매매** | 스피드고 대량등록, 교육 | O | O (자동) |
| 2 | **오너클랜** | 500만 상품, 다팔자 등록 | O | O |
| 3 | **온채널** | 품질 검증, 가격준수 B2B관 | O | O |
| 4 | **도매창고** | DB 다운로드, 고도몰 연동 | O | O |
| 5 | **바나나B2B** | SNS 인기상품, 고급 상세페이지 | O | 수동 |

### 플랫폼별 활용 전략

- **도매매**: 메인 소싱처. 스피드고로 대량 등록 후 성과 측정
- **오너클랜**: 도매매에 없는 카테고리 보완. 알리바바 구매대행도 가능
- **온채널**: 품질 검증 상품 위주. 가격 보호로 마진 안정적
- **도매창고/바나나B2B**: 틈새 상품 발굴용

## 전략 3: 사계절 상품 포트폴리오 구축

### 현재 문제

수영가방(여름) 단일 상품이 매출 63% → 비수기(8~2월) 월 32만원

### 사계절 판매 가능 카테고리

| 카테고리 | 상품 예시 | 시즌 의존도 |
|---------|----------|------------|
| 생활용품 | 보풀제거기, 정리함, 청소용품 | 낮음 |
| 주방용품 | 도마, 밀폐용기, 주방소품 | 낮음 |
| 건강용품 | 마사지볼, 손목보호대, 자세교정 | 낮음 |
| 사무용품 | 모니터 받침대, 케이블 정리 | 낮음 |
| 반려동물 | 장난감, 간식용기, 리드줄 | 낮음 |
| 욕실용품 | 수건걸이, 배수구 필터, 치약짜개 | 낮음 |

### 상품 선정 기준 (위탁판매용)

1. **도매매 위탁 가격 5,000~15,000원** — 너무 싸면 마진 없고, 너무 비싸면 회전 낮음
2. **쿠팡 검색량 있는 키워드** — 쿠팡 자동완성으로 수요 확인
3. **경쟁 셀러 50명 이하** — 리뷰 100개 미만 셀러가 1페이지에 있으면 진입 가능
4. **반품률 낮은 상품** — 의류 제외 (사이즈 이슈), 파손 위험 낮은 것
5. **무게 가벼운 것** — 배송비 최소화

### 포트폴리오 구성 목표

```
여름 (5~7월): 수영가방 + 여름 소품 3~5종 → 월 300만원+
봄/가을 (3~4, 8~10월): 사계절 상품 10종 → 월 100만원
겨울 (11~2월): 사계절 상품 + 겨울 소품 → 월 80만원

→ 연 평균 월 매출 160만원 × 마진 30% = 월 순이익 48만원 (상품만)
→ + 광고 최적화 효과 → 월 60만원+ 가능
```

## 전략 4: 광고비 최적화 — 23.5% → 15%

### 100원당 순이익 공식 (장사왕)

```
100원당 순이익 = 100 × (ROAS × 마진율 − 1)
```

| 마진율 | ROAS 3.0x | ROAS 4.0x | ROAS 5.0x |
|--------|-----------|-----------|-----------|
| 20% | -40원 (적자) | -20원 (적자) | 0원 (BEP) |
| 25% | -25원 (적자) | 0원 (BEP) | +25원 |
| 30% | -10원 (적자) | **+20원** | +50원 |
| 35% | +22원 | +40원 | +75원 |

### 현재 캠페인별 판단

| 캠페인 | ROAS | 마진율 30% 기준 | 판단 |
|--------|------|----------------|------|
| young | 17x | +410원 | **확대** |
| kid | 6.6x | +98원 | 유지 |
| summer | 3.1x | -7원 | **축소** |
| Ai 캠페인 | 0.4x | -88원 | **즉시 중단** |
| 테스트 | 1.5x | -55원 | **즉시 중단** |
| 성과광고 | 0.6x | -82원 | **즉시 중단** |

### 실행 규칙

1. **100원당 순이익 0원 미만 캠페인 → 즉시 중단** (적자 4개 = 월 80만원 낭비)
2. **순이익 양수 캠페인만 예산 배분** (young에 집중)
3. **새 캠페인 시작 시**: 3일 테스트 → 100원당 순이익 계산 → 양수면 유지, 음수면 중단
4. **광고비 상한**: 순이익의 40% 이하로 설정

## 전략 5: 오가닉 매출 16.6% → 30%+

### 쿠팡 검색 최적화 (SEO)

1. **상품명 최적화**
   - 핵심 키워드를 앞 40자 이내에 배치 (쿠팡 검색 노출 가중치)
   - 태그 20개 모두 활용
   - 예: "수영가방" → "수영가방 방수 비치백 대용량 물놀이 가방"

2. **상세페이지 품질**
   - 이미지 최소 5장 (139% CTR 향상 효과)
   - 상품 특징 3~5줄 불릿포인트
   - 사이즈/재질 상세 표기 → 반품률 감소

3. **첫 5일이 핵심**
   - 신규 등록 후 5일 내 전환이 검색 순위 결정
   - 첫 5일간만 광고 집중 → 이후 오가닉 순위 확보 시 광고 축소
   - 2~4주 후 자연 순위 안정화

4. **리뷰 확보**
   - 쿠팡 포토리뷰 유도 (포장 내 안내 카드는 정책 위반 주의)
   - 리뷰 10개 이상 → 오가닉 노출 급증

### 위탁판매에서 오가닉 높이는 핵심

위탁판매는 같은 상품 셀러가 수십명이므로:
- **번들/세트** 구성으로 차별화 (수영가방 + 방수팩 세트)
- **상세페이지 차별화** — 도매매 기본 이미지 말고 직접 편집
- **틈새 키워드** 공략 — 대표 키워드 대신 롱테일 키워드

## 위탁판매의 현실적 한계

위탁판매만으로 **월 100만원 순이익**은 매우 어려움. 현실적 상한:

| 방식 | 월 순이익 상한 | 조건 |
|------|-------------|------|
| 도매꾹 드롭쉬핑 (현재) | 30~40만원 | 광고 최적화 후 |
| 도매매 위탁 전환 | 50~70만원 | 상품 30종+, 광고 최적화 |
| 위탁 + 독점 소싱 | 80~120만원 | 소수 상품 독점 계약 |
| 자사 브랜드 전환 | 100만원+ | 완전히 다른 비즈니스 |

**위탁판매 월 60만원이 현실적 목표.** 그 이상은 소싱 구조 자체를 바꿔야 함.
