## 현재 상태 요약

**테스트 단계: 77개 활성 상품, 평균 마진 48.42%**

셀픽스는 2026년 2월 12일부터 도매꾹 자동 소싱 파이프라인을 가동하기 시작했다. 약 17일간 162개 상품을 소싱하여 77개를 활성 상태로 등록했다. 이 중 5개가 쿠팡에 최종 등록(registered) 완료되었고, 72개는 승인(approved) 상태로 등록 대기 중이다.

주요 상품 카테고리는 수납/정리용품, 주방/생활용품, 차량용품, 패션 악세사리 등 생활잡화 위주이며, 판매가는 15,000원~253,500원 범위에 분포한다. 1~3만원대 상품이 전체의 50.6%로 가장 많다.

**아직 실제 판매 데이터(주문 수, 매출액, 반품율)는 수집되지 않은 상태**이므로, 현재 수치는 모두 등록가 기준의 잠재 가치이다.

## 개선 필요 사항

### 1. 실제 판매 데이터 수집 (최우선)
- 현재 쿠팡 판매량, 실제 매출, 반품율 데이터 없음
- 쿠팡 Open API의 판매 통계 API 연동 필요
- 등록가 기준 마진이 아닌 실질 마진 파악 필수
- **영향**: 수익성 판단, 상품 전략 수립 불가

### 2. 품절 모니터링 강화
- 47개(29.0%)가 품절 처리 -- 약 3개 중 1개꼴
- 현재 6시간 주기 품절 감지 크론 운영 중이나, 품절 상품 대체 소싱 자동화 필요
- POIPOI 브랜드 상품에서 품절이 집중 발생
- **영향**: 판매 기회 손실, 고객 경험 저하

### 3. 소싱처 다각화
- 도매꾹 100% 의존 -- 단일 장애점(SPOF)
- 사입삼촌, 오너클랜, 1688(중국 직소싱) 등 추가 소싱처 검토 필요
- **영향**: 품절 리스크 분산, 상품 다양성 확보

### 4. 카테고리 데이터 정비
- `categoryName` 필드가 대부분 `null` -- 카테고리별 분석 불가
- 쿠팡 카테고리 매핑 자동화 필요
- **영향**: 카테고리별 성과 분석, 전략적 소싱 방향 설정 불가

### 5. 가격 경쟁력 분석
- 현재 원가 대비 약 5배 마크업으로 설정
- 쿠팡 내 동일 상품 가격 비교 데이터 없음
- 경쟁가 대비 가격 포지셔닝 검토 필요
- **영향**: 과도한 마크업 시 판매 전환율 하락 가능
