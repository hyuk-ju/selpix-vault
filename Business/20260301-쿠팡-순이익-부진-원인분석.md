# 쿠팡 순이익 부진 원인 분석

> 10개월 매출 1,447만원인데 순이익 293만원(월 29만원)밖에 안 되는 이유

## 한줄 진단

**광고비 과투자(23.5%) + 시즌 편중(2개월에 82%) + 위탁판매 구조적 한계(오가닉 17%)** 3개가 맞물려서 매출은 나오지만 남는 게 없는 구조.

## 돈이 새는 6개 구멍

```
매출 14,467,260원 (100%)
│
├─① 원가 42.0%    -6,078,830원  ← 도매꾹 드롭쉬핑 배송비 부담
├─② 광고비 23.5%  -3,398,265원  ← 업계 적정(10~15%)의 2배
├─③ 수수료 11.5%  -1,660,913원  ← 쿠팡 고정 (개선 불가)
├─④ 쿠폰 2.8%      -400,000원  ← 순이익의 14%를 쿠폰에
│
└─ 순이익 20.2%  +2,929,252원
```

## 원인 1: 광고비가 매출의 23.5% — 업계 기준 2배

| 기준 | 광고비/매출 비율 |
|------|----------------|
| 업계 적정 | 10~15% |
| 업계 공격적 | 15~20% |
| **현재** | **23.5%** ← 과투자 |

**적자 캠페인에 80.4만원 낭비:**

| 캠페인 | 광고비 | 매출 | ROAS | 손실 |
|--------|--------|------|------|------|
| Ai 캠페인 | 35.7만 | 15.4만 | 0.4x | -29만 |
| 테스트 상품 | 35.4만 | 54만 | 1.5x | -10만 |
| 성과광고 | 6.8만 | 4.3만 | 0.6x | -5만 |
| 가을겨울 | 2.5만 | 0 | 0x | -3만 |

이 4개만 안 했어도 순이익 +80만원.

**업계 가이드 (출처: [장사왕](https://www.sellerking.io/blog/coupang-ads-roas-profit))**:
- 순이익의 30~40%를 광고비 한도로 설정
- End ROAS(최소 ROAS) 이하 캠페인은 즉시 중단
- ROAS 높이기보다 "순이익 금액 극대화"에 집중

## 원인 2: 매출이 2개월에 집중 (82%)

```
2025-06: ████████████████████████████  788만원
2025-07: ██████████████               399만원
나머지8개월: ████                       259만원 (전체)
```

- **6~7월**: 1,188만원 (82.1%)
- **나머지 8개월**: 259만원 (17.9%) — 월평균 32만원
- **2월**: 매출 0원

수영가방이 전체 매출의 63%인데 여름에만 팔림. **사계절 상품이 없다**는 게 근본 문제.

## 원인 3: 130개 등록, 매출 상품 소수

- 과거 등록 상품: 130개
- 현재 활성 상품: 10개
- 실제 매출 발생: 소수 (수영가방, 라이터, 우산 등)

→ 도매꾹에서 대량 자동 등록했지만 대부분 매출 0원 = **소싱 적중률 매우 낮음**

## 원인 4: 도매꾹 드롭쉬핑 원가 구조

| 항목 | 도매꾹 건별 | 중국 사입 |
|------|-----------|----------|
| 수영가방 단가 | 7,427원 | 2,761원 |
| 배송비 | 건당 2,700원 추가 | 대량 배송 포함 |
| 원가율 | 37~47% | 14~17% |

도매꾹 건별 드롭쉬핑은:
- 주문마다 **배송비 2,700~3,000원** 추가 (상품금액의 15.5%)
- 같은 상품을 중국 사입하면 **63% 저렴**

## 원인 5: 오가닉 매출 16.6% — 구조적 한계

| 셀러 유형 | 오가닉 비율 |
|----------|-----------|
| 건강한 셀러 (자사 브랜드) | 50%+ |
| 보통 셀러 | 30~40% |
| **현재** | **16.6%** |

위탁판매 특성상:
- 같은 상품 파는 셀러가 수십명 → 검색 순위 확보 어려움
- 리뷰 수도 적음 → 광고 없이 노출 자체가 안 됨
- 광고 끄면 월 매출 24만원, 마진 11만원

## 원인 6: 판매자 쿠폰 40만원

- 순이익 293만원의 **13.7%**를 쿠폰에 지출
- 쿠폰이 실제로 전환율을 얼마나 올렸는지 검증 안 됨

## 근본 질문

> 위탁판매(도매꾹 드롭쉬핑)로 월 100만원 이상 순이익을 낼 수 있는가?

업계 현실:
- 위탁판매로 월 100만원 순이익은 **매우 어려움** ([출처](https://llily.co.kr/스마트스토어-쿠팡-위탁판매-현실-후기/))
- 마진율 15~25%가 현실적 ([출처](https://oscsnm.com/coupang-dropshipping-guide-2025/))
- 2025년 쿠팡 정책 변화로 마진이 전년 대비 8%p 감소
- 성공 사례는 대부분 **자사 브랜드 or 독점 소싱**으로 전환한 경우

현재 구조(도매꾹 위탁 + 광고 의존)로는 **월 50만원이 현실적 상한선**. 월 100만원 이상을 원하면 **소싱 구조 자체를 바꿔야** 함 (자사 브랜드, 중국 직소싱, 독점 계약 등).
