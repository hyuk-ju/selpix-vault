# 💡 아이디어 실험실 운영 규칙

> 목적: 운영 대화와 아이디어 대화를 분리해, 채택된 아이디어를 빠르게 실행 가능한 카드로 전환한다.

## 1) 승격 트리거 문구 (운영 메인에서 사용)
아래 문구가 나오면 아이디어를 **아이디어 실험실**로 승격 전송한다.

- `이거 채택`
- `아이디어로 넘겨`
- `이건 실험실로 이동`
- `실험 카드 만들어`

### 트리거 처리 규칙
1. 현재 대화 요약 3~5줄 생성
2. 실행용 아이디어 카드 1개 생성
3. 아이디어 실험실 토픽으로 후속 대화 시작

## 3) 토픽 전환 운영 규칙 (1페이지)

### 토픽 역할
- **운영 메인(31)**: 의사결정, 크론/장애/우선순위
- **아이디어 실험실(177)**: 유입/콘텐츠/퍼널/실험 설계

### 전환 규칙
1. 운영 메인에서 아이디어가 채택되면 트리거 문구로 승격
2. 아이디어 실험실에서 카드 기반으로만 대화
3. 실험 종료 후 결과 요약을 운영 메인으로 역전송

### 보고 형식
- 운영 메인: 결정/근거/다음 액션 중심
- 아이디어 실험실: 가설/실험/KPI/회고 중심

### 금지 사항
- 같은 아이디어를 두 토픽에서 병렬 진행 금지
- 카드 없이 장문 브레인스토밍만 반복 금지

### SLA
- 승격 후 10분 내 카드 초안 생성
- 실험 결과는 24시간 내 운영 메인에 요약 전송

---

## 4) 운영 플로우 (요약)
1. 운영 메인에서 아이디어 논의
2. 트리거 문구로 승격
3. 아이디어 카드 생성
4. 아이디어 실험실에서 7일 실행
5. 결과를 운영 메인으로 회수
