## 5) 배운 점 / 패턴
- host-runtime과 npm global은 별개 — npm 업데이트해도 실행 바이너리는 host-runtime에서 로드됨
- systemd 서비스 파일에 OPENCLAW_SERVICE_VERSION이 하드코딩 — 업데이트 시 같이 수정 필요
- Anthropic OAuth는 OpenClaw 등 제3자 도구에서 정지 위험 — Codex OAuth 또는 API 키만 사용
- xhigh는 gpt-5.3-codex 전용, Spark(속도특화)에서는 미지원
- Spark는 OAuth에서 사용 불가, Pro + API 키 필요
- **`~/.openclaw/`와 `~/openclaw/config/` 이중 경로 문제** — `OPENCLAW_STATE_DIR` 환경변수를 `.profile`에 등록해서 해결. `.bashrc`가 아닌 `.profile`에 넣어야 로그인 쉘에서도 적용됨 (`.bashrc`는 non-interactive 가드에서 return)
- **`openclaw onboard`는 항상 STATE_DIR에 저장** — 환경변수 미설정 시 기본 `~/.openclaw/`에 저장되므로 반드시 `.profile`에 설정 필요
