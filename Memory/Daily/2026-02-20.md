오늘은 **아이디어 실험실 시스템 고도화** 세션. 여러 가지 핵심 기능 추가/수정함.

## ✅ 완료 항목

### 1. Fast Track 시스템 구현 (`run_idea_discussion.js`)
- `type == "openclaw"` 아이디어는 4단계 중 `trend`/`biz` 자동 skipped
- skipped 단계는 텔레그램 카드와 Vault 마크다운에서 graceful하게 처리
- ADR에도 Fast Track 여부 반영
- `computeVerdict`에서 openclaw 아이디어는 tech 1개 판정 기준으로 감소

### 2. Fast Track 전용 버튼 커스터마이징
- openclaw 아이디어 최종 카드 버튼 변경:
  - 기존: `사업계획서` / `깊게 파기`
  - 변경: `🗑 패스` / `🔍 레퍼런스 조사 더 하기 (idea:deepfast)` / `🛠 적용 하기 (idea:code)`

### 3. `idea-lab-loop` 크론 자동화 고도화 (`jobs.json`)
- 스케줄: 매일 09:30 → **매 1시간마다** 변경 (즉각 자동 진행)
- 프롬프트에 Fast Track 분기 명시:
  - `type == "openclaw"`: trend/biz spawn 금지, tech+critic만 진행
  - `type != "openclaw"`: 기존 4단계 그대로

### 4. `idea:deepfast` 콜백 + Fast Track 레퍼런스 조사 모드
- `AGENTS.md`에 `idea:deepfast` 핸들러 추가
- ops-dev (GitHub/npm/블로그) + trend-scout (트위터/유튜브 스킬 사용) **병렬 spawn**
- 시장/비즈니스 분석은 여전히 생략, tech+critic만 재실행

### 5. 텔레그램 모드 선택 메시지 (`process_idea.js`)
- `idea:deep:ID` 콜백이 openclaw 아이디어에서 눌리면:
  - 풀 4단계 바로 실행 ❌
  - 대신 아이디어 실험실 토픽에 **모드 선택 버튼 메시지 전송** ✅
  - `[🔍 레퍼런스만 조사]` → `idea:deepfast` → Fast Track 유지
  - `[📊 풀 4단계 재분석]` → `idea:deepfull` → 전체 재분석
- 일반 아이디어는 버튼 없이 바로 풀 4단계 진행
- `--deep`, `--deepfast` CLI 명령어 추가

### 6. `process_approval.js` 개선
- `pending_approvals.json` 없을 때 자동 생성 + 경고 로그
- 승인/거절/만료 시 원본 텔레그램 버튼 메시지를 `editMessage`로 수정 → 버튼 자동 제거
- 기처리/만료된 버튼 클릭 시 의미 있는 한국어 안내 메시지 전송
