## 5) 배운 점 / 패턴
- **bundled 스킬은 host-runtime npm 패키지에 내장** — workspace/skills/ 삭제로는 제거 불가, `openclaw skills list`로 확인
- **스킬 캐시는 세션에 바인딩** — 스킬 폴더 정리 후 sessions.json 초기화 필요
- **openclaw agent CLI 타임아웃**: `--timeout` 플래그가 `agents.defaults.timeoutSeconds` 보다 우선
- host-runtime과 npm global은 별개 — npm 업데이트해도 실행 바이너리는 host-runtime에서 로드됨
- systemd 서비스 파일에 OPENCLAW_SERVICE_VERSION이 하드코딩 — 업데이트 시 같이 수정 필요
- Anthropic OAuth는 OpenClaw 등 제3자 도구에서 정지 위험 — Codex OAuth 또는 API 키만 사용
- xhigh는 gpt-5.3-codex 전용, Spark(속도특화)에서는 미지원
- ~~Spark는 OAuth에서 사용 불가~~ → **수정: OAuth Pro에서도 `/model spark`로 전환 가능!**
- **`~/.openclaw/`와 `~/openclaw/config/` 이중 경로 문제** — `OPENCLAW_STATE_DIR` 환경변수를 `.profile`에 등록해서 해결
- **`openclaw onboard`는 항상 STATE_DIR에 저장** — 환경변수 미설정 시 기본 `~/.openclaw/`에 저장
- **모델 변경 시 3곳 동시 수정 필수**:
  1. `openclaw.json` → `agents.list[].model.primary` (어떤 모델)
  2. `openclaw.json` → `auth.profiles` (어떤 인증 프로바이더)
  3. `sessions.json` → 기존 세션 캐시 초기화 (또는 세션 삭제)
- **`sessions.json`은 모델을 세션 키 단위로 캐시** — config만 바꾸면 기존 세션에 적용 안 됨
