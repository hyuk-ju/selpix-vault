## `openclaw` 메모리 운영 기준

- 장기 메모리는 `openclaw/config/workspace/MEMORY.md`에 축적.
- 일일 이벤트 로그는 `openclaw/config/workspace/memory/YYYY-MM-DD.md`에 원본 그대로 기록.
- 최근 맥락은 오늘/어제 일일 파일 우선 조회.
- 프로젝트 간 의사결정이 섞일 때는 `MEMORY.md`에 주제별로 정리해 장기 유지한다.
- 2026-02-14: OpenClaw 메모리 파일(`memory/`) 존재를 확인했고, 실제 검색 자동화는 API 연동 여부와 별개로 `memory/*.md` 중심으로 동작하도록 정리.
