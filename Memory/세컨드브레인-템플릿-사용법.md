# 🛠 세컨드브레인 템플릿 사용법 (실전 가이드)

> 대상: Obsidian으로 셀픽스/쿠팡/리서치 운영 기록을 체계화하려는 사용자를 위한 가이드

---

## 0) 왜 이 템플릿을 쓰는가

핵심은 3가지입니다.

1. **저장보다 연결**: 노트를 쌓는 게 아니라 찾히게 만든다.
2. **수집과 해석 분리**: 정보 수집은 빠르게, 의사결정은 내 해석으로.
3. **짧은 운영 루틴**: 매일 10분 + 주 30분 + 월 30분으로 유지 가능.

## 2) Obsidian에서 실제 적용 방법

### A. 템플릿 기능 켜기
1. Obsidian → **Settings** → **Core plugins**
2. **Templates** 활성화
3. Templates 설정에서 **Template folder location**을 `Templates`로 지정

### B. 템플릿 삽입
1. 새 노트 생성
2. 커맨드 팔레트(`Ctrl/Cmd + P`) → `Templates: Insert template`
3. 원하는 템플릿 선택

### C. 파일 네이밍 규칙 (권장)
- 회의록: `회의록_YYYY-MM-DD_주제`
- 클리핑: `클리핑_YYYY-MM-DD_키워드`
- MOC: `MOC_주제`
- Daily: `Memory/Daily/YYYY-MM-DD`

## 3) 템플릿별 사용법 (언제/어떻게)

## 3-1) 회의록 템플릿
**언제 쓰나**
- 의사결정이 있는 회의
- TODO/담당/마감이 생기는 대화

**작성 핵심**
- `결정사항`과 `실행 항목`을 반드시 분리
- `내 해석`에 "진짜 중요한 포인트"를 3줄로 남김

**좋은 예시(짧게)**
- 결정: SEO 업로드 시간을 오전으로 고정
- 이유: 오후 반려 대응 시간을 확보하기 위해
- 담당/마감: 장 / 내일 10:00

---

## 3-2) MOC 템플릿
**언제 쓰나**
- 노트가 10개 이상 쌓인 주제
- 검색만으로 찾기 어려워진 영역

**작성 핵심**
- MOC는 요약문서가 아니라 **탐색 인덱스**
- 각 링크 옆에 "왜 중요한지" 1줄 주석 필수

**운영 팁**
- 주 1회 Inbox 노트를 MOC에 3개 이상 연결
- 고립 노트(링크 0개) 우선 연결

---

## 3-3) 클리핑 템플릿
**언제 쓰나**
- 유튜브/아티클/트위터/문서에서 인사이트를 가져올 때

**작성 핵심**
- `source_url`은 표준 필드로 고정
- `내 해석`을 안 쓰면 클리핑 품질 50% 이하

**최소 작성 기준(절대 최소)**
- 원문 요약 3줄
- 핵심 포인트 3개
- 내 해석 3문장
- 적용 아이디어(오늘 1개)

---

## 3-4) Daily Note 템플릿
**언제 쓰나**
- 매일 시작/마감 루틴

**작성 핵심**
- `오늘의 결정`과 `내일 Top 3`만 제대로 써도 운영 품질이 올라감
- 만든 노트를 Daily에 링크해서 회상 경로를 만든다

**루틴 예시**
- 오전 시작 5분: Top3 작성
- 저녁 마감 5분: 결정/배운점/링크 정리

---

## 4) 운영 루틴 (이대로만 하면 됨)

### 매일 (10분)
1. Daily Note 생성
2. 오늘 생성한 회의록/클리핑 링크 추가
3. 내일 Top3 작성

### 매주 (30분)
1. Inbox 정리
2. MOC 업데이트(최소 3개 링크 연결)
3. 고립 노트 연결

### 매월 (30분)
1. Graph View 필터로 구조 점검
2. 주제별 MOC 품질 점검
3. 불필요/중복 노트 정리

---

## 5) 그래프 뷰 사용법 (실전)

### 필수 필터
- Graph View → Filters에 아래 입력:

```text
-path:"Memory/Daily"
```

효과:
- 날짜 일지 노드 폭주를 줄이고, 주제 노트 연결 구조가 잘 보임

### 추천 점검 방식
- 키워드 검색 후 depth 1~2로만 탐색
- 고립 노드 발견 시 관련 노트 1개 이상 링크 추가

---

## 6) 자주 하는 실수 & 해결

1. **실수:** 클리핑만 쌓고 해석이 없음  
   **해결:** `내 해석` 미작성 노트는 미완료로 간주

2. **실수:** 회의록에 실행 담당/마감 누락  
   **해결:** Action Items 표를 빈칸 없이 채우기

3. **실수:** MOC를 업데이트 안 함  
   **해결:** 매주 금요일 30분 고정 슬롯 배정

4. **실수:** Daily가 단순 일기화됨  
   **해결:** 반드시 "결정"과 "내일 Top3" 포함
