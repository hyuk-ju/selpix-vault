## 3. 타겟 고객

- **페르소나:** 직원 1~30인 이커머스/콘텐츠 운영팀 대표 또는 운영리드(비개발자 포함), PC 상시대기 부담이 큰 팀
- **핵심 문제:**
  1. 주문/문의/재고/콘텐츠 승인 업무가 분산되어 대응 누락이 잦음
  2. 외근·이동 중에도 운영 의사결정을 내려야 하나 도구가 분절됨
  3. 자동화 도입 의지는 있으나 n8n/Make/Zapier를 직접 설계·유지할 인력이 부족
- **지불 의향:** 초기 세팅비 80만~200만원 + 월 유지비 12만~60만원 구간 수용 가능(업무시간 절감/응답속도 개선이 수치로 증명될 때)

## 4. 제품 전략

- **핵심 가치:** 텔레그램 한 채널에서 운영 지휘(명령/승인/알림)를 수행하고, Node.js 기반 오케스트레이션으로 주문·문의·재고·콘텐츠 루프를 자동 실행
- **차별화:** 범용 자동화 툴 판매가 아니라 '모바일 지휘 UX + 업종별 운영 템플릿 + 세팅대행 + 유지보수 SLA'를 패키지로 제공
- **기술 스택:** Backend: Node.js 22 + TypeScript + Fastify, Queue: BullMQ/Redis, DB: PostgreSQL, Workflow bridge: n8n Webhook/API, Infra: Docker Compose/K8s-ready, Observability: Sentry + OpenTelemetry, Auth: JWT + RBAC
- **MVP 기능:**
  1. 모바일 지휘 명령 10종(/orders, /inbox, /stock, /approve, /pause 등)
  2. 이벤트 인입 3종(주문/문의/재고) + 우선순위 라우팅
  3. 승인 플로우(2인 승인 옵션) + 감사로그
  4. 실패 재시도 큐 + 수동 롤백 버튼
  5. 일일 운영 다이제스트(처리량/지연/오류) 자동 발송
