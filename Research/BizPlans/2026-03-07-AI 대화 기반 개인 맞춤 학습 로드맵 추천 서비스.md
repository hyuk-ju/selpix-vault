## 3. 타겟 고객

- **페르소나:** 25-39세 직장인/취준생(개발·데이터·영어 역량 강화 필요, 주당 5~7시간 학습 가능)
- **핵심 문제:**
  1. 무엇부터 배워야 할지 몰라 시작 지연
  2. 학습 계획이 현실 일정과 맞지 않아 중도 이탈
  3. 추천 자료가 많아도 개인 목표/수준에 맞는 우선순위 판단이 어려움
- **지불 의향:** 개인 B2C 월 15,000~39,000원 수용 가능, 성과 체감(시간절감/완주율 개선) 시 상위요금제 전환 의향

## 4. 제품 전략

- **핵심 가치:** 대화 기록에서 목표·수준·제약을 자동 추출해 즉시 실행 가능한 4~8주 학습 로드맵과 복습 루틴을 생성하고, 매주 성과 기반으로 재계획한다.
- **차별화:** (1) 대화 맥락 기반 자동 진단, (2) 실행률 중심 주간 리플랜 루프, (3) 성과지표(완료율/재학습률) 기반 개인화 강화
- **기술 스택:** Node.js(NestJS) + PostgreSQL(pgvector) + Redis(BullMQ) + OpenAI API + Docker Compose(api/worker/db/redis) + React(관리 UI)
- **MVP 기능:**
  1. 대화 로그 업로드/정제(JSON/TXT)
  2. 학습 프로필 추출(목표/수준/가용시간/선호)
  3. 주차별 로드맵 생성 + 일일 할일
  4. 추천 교재/강의 Top-N + 선택 근거
  5. 진도 체크 및 주간 리플랜
  6. 학습 리포트(완료율/지연요인/다음 액션)

## 5. 수익 모델

- **모델:** B2C 구독 + B2B 팀 라이선스 하이브리드
- **단위 경제:** 가정: ARPPU 19,000원, 변동비 2,500원/유료유저, 공헌이익 16,500원(마진 86.8%), CAC 120,000원 기준 회수기간 약 7.3개월. 목표는 CAC 90,000원 이하 및 LTV/CAC 2.5 이상.
- **손익분기:** 월 고정비 35,000,000원 가정 시 B2C 단독 BEP 약 2,122 유료유저. B2B 월 150만원 고객 10곳 확보 시 B2C BEP를 약 1,200명 수준으로 완화 가능.

## 8. 코딩 스펙 (bkit PDCA)

- **프로젝트명:** ai-study-roadmap
- **레벨:** dynamic

### 구현 기능
1. 대화로그 수집·정제 파이프라인
2. 학습 프로필 추출 엔진
3. 주차별 로드맵 생성
4. 추천 리소스 랭킹 + 근거 저장
5. 진도 수집 및 주간 리플랜
6. 관리자/사용자 대시보드

### API 엔드포인트
| Method | Path | 설명 |
|--------|------|------|
| POST | /api/v1/conversations/import | 대화 로그 업로드 및 정제 작업 큐 등록 |
| POST | /api/v1/profiles/extract | 목표/수준/가용시간/선호 자동 추출 |
| POST | /api/v1/roadmaps/generate | 4~8주 학습 로드맵 생성 |
| POST | /api/v1/roadmaps/:id/replan | 진도 기반 리플랜 생성 |
| GET | /api/v1/roadmaps/:id/report | 완료율/지연요인/다음주 계획 리포트 조회 |
| POST | /api/v1/feedback | 추천 수용/거절 및 만족도 피드백 저장 |
