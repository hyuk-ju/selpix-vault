# 사업계획서: AI 대화 기반 개인 맞춤 학습 로드맵 추천 서비스

> 채팅형 AI 대화 기록을 구조화해 목표 과목별 학습 로드맵과 교재/도서를 추천하는 서비스

3. B2C 단독보다 B2B2C(교육기관/기업 연계) 수익 안정성 선호

## 3. 타겟 고객

- **페르소나:** 취업/이직 준비 중인 20~39세 자기주도 학습자
- **핵심 문제:**
  1. 무엇부터 배워야 할지 우선순위 설정이 어렵다
  2. 계획을 세워도 2~3주 내 이탈한다
  3. 자료가 너무 많아 본인 수준에 맞는 선택이 어렵다
- **지불 의향:** 월 1.5만~3.9만원 구독은 수용 가능, 성과 체감 시 상위 플랜 전환 가능

## 4. 제품 전략

- **핵심 가치:** 대화 로그에서 목표/수준/시간 제약을 추출해 실행 가능한 주차별 학습 로드맵과 복습 루틴을 자동 설계
- **차별화:** 일반 챗봇 답변이 아닌 '학습 설계(진단→계획→실행→피드백)' 폐쇄루프와 성과지표 기반 리플래닝
- **기술 스택:** Next.js + NestJS + PostgreSQL(pgvector) + Redis + BullMQ + OpenAI/Claude API + Docker Compose
- **MVP 기능:**
  1. 대화 기록 업로드/파싱(JSON·텍스트)
  2. 목표·레벨·가용시간 자동 추출 + 사용자 보정 UI
  3. 4~8주 로드맵 생성(주차별 체크리스트)
  4. 교재/강의/문서 추천 + 추천 근거 표시
  5. 주간 리뷰/리플래닝(이탈 감지 시 재계획)
  6. 성과 대시보드(완료율/학습시간/지연 구간)

## 5. 수익 모델

- **모델:** B2C 구독 + B2B2C 기관 라이선스 + 제휴 수수료
- **단위 경제:** 유료 사용자당 매출 19,000원, 변동비 2,500원, 공헌이익 16,500원(약 86.8% margin)
- **손익분기:** B2C 단독 약 2,122명 유료 사용자 필요, B2B 라이선스 10개 확보 시 약 1,200명대로 완화
