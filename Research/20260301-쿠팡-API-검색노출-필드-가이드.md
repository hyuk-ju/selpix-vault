# 쿠팡 API 검색 노출 필드 가이드

> Open API로 상품 등록 시 각 필드가 검색/노출에 미치는 영향 정리

## 1. 필드별 검색 가중치

| 필드 | 검색 가중치 | 역할 | 비고 |
|------|-----------|------|------|
| `displayProductName` | ★★★★★ | 검색 결과 상품명 | 앞 40자에 가중치 집중 |
| `generalProductName` | ★★★★ | 일반 상품명 | displayName과 동일하게 설정 |
| `searchTags[]` | ★★★★ | 검색 태그 (최대 20개) | displayName에 없는 동의어/롱테일 |
| `brand` | ★★★ | 브랜드명 | 브랜드 필터 + 검색 매칭 |
| `items[].searchTags[]` | ★★★ | 아이템별 검색 태그 | 옵션별 키워드 확장 |
| `attributes` (EXPOSED) | ★★ | 검색 필터 + SRP 표시 | 아래 상세 참고 |
| `items[].itemName` | ★ | 쇼핑카트/주문 항목명 | 검색 색인에 거의 미포함 |
| `notices[]` | ★ | 상품 고시 정보 | 검색 비가중 |

## 2. `exposed: 'EXPOSED'` 정확한 동작

### SRP (Search Results Page) 동작

`exposed: 'EXPOSED'`로 설정된 속성값은 **검색 결과 페이지에서 상품명 뒤에 자동 표시**된다.

```
displayProductName: "해피바스 솝베리 클렌징 오일"
attributes: [{ attributeTypeName: "용량", attributeValueName: "200ml", exposed: "EXPOSED" }]

→ SRP 표시: "해피바스 솝베리 클렌징 오일 200ml"
```

### SDP (Single Detail Page) 동작

상세페이지에서는 EXPOSED 속성이 **옵션 선택 영역에 별도 표시**되므로 타이틀에서 제외될 수 있다.

### EXPOSED vs NONE 비교

| `exposed` 값 | SRP (검색결과) | SDP (상세) | 검색 필터 |
|---|---|---|---|
| `EXPOSED` | 상품명 뒤에 자동 표시 | 옵션 선택 영역에 표시 | 활성화 |
| `NONE` | 표시 안 됨 | 상세 정보에만 표시 | 비활성화 |

### EXPOSED 결정 조건 (카테고리 메타 기준)

```
required: "MANDATORY" + groupNumber: "NONE" → EXPOSED (필수 단독)
required: "OPTIONAL" + groupNumber: "1"     → EXPOSED (선택적 그룹)
```

## 3. `displayProductName` 규칙

### 글자수 제한

| 시기 | 최대 글자수 |
|------|-----------|
| ~2024.03.26 | 150자 |
| 2024.03.27~ | **100자** (Open API) |
| 2025.10~ | 정책상 120자 허용 가능하나, **우리 코드는 100자 검증** |

권장: **80자 이하** (모바일 가독성)
> **주의**: `cron_register_product.js` `validatePayload()`에서 100자 초과 시 거부. 120자로 변경하려면 코드도 수정 필요.

### 공식 구조

```
[브랜드/제조사] + [제품명] + [상품 유형(카테고리)] + [노출 속성(Exposed)]
```

### 금지 사항

- 특수문자: `!`, `$`, `?`, `*`, `@`, `#`, `~`, `<`, `>`, `[`, `]`, `|`
- 동일 단어 3회 이상 반복
- 프로모션 문구: 무료배송, 할인, 세일, 최저가, 1+1, 한정수량, 특가, 이벤트, 초특가, 사은품, 증정, 당일출고, 빠른배송, 즉시발송, 당일발송, 오늘출발
- 판매자 정보: 상점명, 판매자 ID
- 시즌/이벤트: 크리스마스, 발렌타인데이
- 과도한 마케팅: 신상, 베스트, 1위, 인기, BEST, HOT, 추천, 정품, 공식몰, 리뷰이벤트
> 코드 검증: `FORBIDDEN_WORDS` Set + `FORBIDDEN_CHARS_RE` 정규식으로 자동 거부

### 브랜드 없는 경우

- 쿠팡 공식: `brand` 필드에 빈 문자열 `""` 사용
- 상품명을 브랜드 필드에 넣으면 안 됨
- 검색 필터에서 "비브랜드"로 분류됨

## 4. `displayProductName` vs `itemName` 관계

```
displayProductName: "텀블러 보온병 스텐 500ml"  ← 검색 결과에 보임
  └── items[0].itemName: "화이트"               ← 옵션 선택/카트에 보임
  └── items[1].itemName: "블랙"                 ← 옵션 선택/카트에 보임
  └── items[2].itemName: "실버"                 ← 옵션 선택/카트에 보임
```

- `displayProductName`은 **검색 인덱싱의 핵심 필드**
- `itemName`은 **검색에 직접 영향 없음** (쇼핑카트 표시용)
- 경쟁사가 상품명에 사이즈/색상을 직접 넣는 이유: `displayProductName`이 검색 랭킹을 결정하므로

## 5. `searchTags` 작성 가이드

### 구조 (20개 슬롯)

```
1~5:   핵심 키워드 (상품명의 주요 단어)
6~10:  동의어/유의어 (텀블러→보온병, 보냉컵)
11~15: 롱테일 조합 (텀블러 500ml, 텀블러 보온)
16~20: 용도/재질/상위분류 (사무실, 선물, 대용량)
```

### DO / DON'T

```
DO:
  - 영어+한국어 병행 (러닝화 + running shoes)
  - 기능 키워드 (UV코팅, 초경량, 글루텐프리)
  - 스타일/용도 (데일리, 웨딩, 캠핑)

DON'T:
  - 카테고리명 그대로 복사
  - 동일 단어 반복
  - 슬래시로 단어 생략 (14/18K X → 14K, 18K O)
```

### `cron_register_product.js` — 등록 시점 처리

```javascript
// displayProductName: prod.displayName (소싱 시 최적화된 이름, 100자 검증)
// brand: '' (비브랜드 빈 문자열 — 항상 공백)
// validatePayload(): 금지 특수문자(!$?*@#~<>[]|) + 금지 키워드 자동 거부

// 속성 처리 파이프라인 (2026-03-03 대폭 개선):
// 1. ensureRequiredAttributes(): 카테고리 메타 기반 필수 속성 자동 생성
// 2. sanitizeAttributesWithMeta(): 메타 데이터와 대조하여 속성값 검증
//    - sanitizeAttributeByMeta(): 개별 속성 검증
//      - NUMBER 타입: 숫자 추출 + basicUnit 자동 붙임 (예: "3" → "3개")
//      - RANGE 타입: 범위값 추출 (extractRangeValue)
//      - allowedValues 불일치 시: pickBestAllowedValue()로 자동 보정
// 3. pickBestAllowedValue(): 5단계 퍼지 매칭
//    - 대소문자/공백 무시 매칭 → 부분 매칭 → 수량 최근접 → 색상 폴백 → 사이즈 FREE 변환

// 재시도 로직: 쿠팡 API 거부 시 attrRetryCount 최대 2회 → 속성 초기화 후 재생성
// items[].searchTags: 소싱 시 생성된 태그 사용
```
