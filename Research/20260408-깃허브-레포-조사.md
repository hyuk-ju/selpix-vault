# GitHub 레포 조사 (2026-04-08)

소셜미디어(unclejobs.ai, zig_mini)에서 발견한 레포 + declaw 확인.

## 1. Karpathy Skills CLAUDE.md — ⭐ 8.1k

- **URL**: https://github.com/forrestchang/andrej-karpathy-skills
- **핵심**: Karpathy AI 코딩 4원칙을 CLAUDE.md로 구현
- **4원칙**: Think Before Coding, Simplicity First, Surgical Changes, Goal-Driven Execution
- **우리 적용도**: 중간. 원칙 2/3/4는 이미 CLAUDE.md에 반영됨. "Think Before Coding" 명시적 추가 검토 가치.
- **결론**: OpenClaw 에이전트 SOUL.md 프롬프트에 "코딩 전 추론 단계" 추가 고려

## 2. CodexBar — ⭐ 10.2k

- **URL**: https://github.com/steipete/CodexBar
- **핵심**: Mac 메뉴바 AI 토큰 사용량 모니터 (20+ 프로바이더)
- **설치**: `brew install --cask steipete/tap/codexbar`
- **우리 적용도**: 낮음. Linux 서버 환경에 해당 없음. `openclaw status`로 토큰 확인 가능.
- **결론**: 패스

## 3. Zigrix "Agent Matrix" — ⭐ 5

- **URL**: https://github.com/owen-ever/zigrix
- **핵심**: OpenClaw 전용 멀티에이전트 오케스트레이션 CLI
- **특징**: 태스크 dispatch → 워커 배정 → evidence 수집 → finalize 리포트
- **아키텍처**: 3-tier (CLI/Core State/Integration), 중앙 상태 `~/.zigrix/`
- **우리 적용도**: 관심 수준. v0.1.1 alpha, 태스크 lifecycle 패턴만 참고.
- **결론**: 시기상조. 62개 크론잡 체계가 이미 작동 중. 복잡성 증가 우려.

## 4. DeClaw (보안 포크) — ⭐ 1

- **URL**: https://github.com/tomstetson/declaw
- **핵심**: OpenClaw 보안 강화 포크 (defense-in-depth)
- **주요 기능**: secret:// URI vault, declaw-doctor 15개 보안체크, 실시간 이상탐지 10-패턴, kill-switch
- **우리 보안 갭 해당**: API 키 plaintext .env, elevated exec wildcard *, 런타임 모니터링 없음
- **결론**: 적용도 높음. declaw-doctor 로직 참고 → system_auditor.js 보안 체크 강화 권장

## 5. DeClaw (워크스페이스 OS) — ⭐ 0

- **URL**: https://github.com/seco/declaw (원본) / https://github.com/hyuk-ju/declaw (포크)
- **핵심**: Claude Code를 범용 워크스페이스 OS로 변환하는 스타터킷
- **구성**: 슬래시 커맨드 12개, 에이전트 4개, 룰 7개, 메모리 3레인, 캐퍼빌리티 팩 5개
- **우리 적용도**: 보완 관계. Claude Code 로컬 개발 환경 정리에 활용 가능.
- **결론**: 내 포크에서 커스터마이즈 진행 여부 검토
