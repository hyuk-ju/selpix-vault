```

  22건 판매 중 (approved 11 + registered 11)

  일일 브리핑 크론도 작동 중
```

**지금 필요한 것**: 이 파이프라인을 성장시킬 방향 선택

## 선택지 A — 쿠팡 파이프라인 확장 (양적 성장)

> "등록 상품 수 늘리기"

### 내용
- 현재 22건 → 목표 100건으로 확장
- 소싱 카테고리 다양화 (현재 잡화 위주 → 특정 카테고리 집중)
- 일일 자동 소싱+등록 크론 구축

### 장점
- 파이프라인 이미 존재, 추가 투자 없이 확장 가능
- 규모의 경제: 상품 많을수록 매출 자연 증가

### 단점
- 도매꾹 품질 제한 (이미지 퀄리티, 설명 품질)
- 경쟁 많은 카테고리에서 단순 등록만으론 한계

### 필요한 것
- 소싱 자동화 고도화 (키워드 기반 자동 발굴)
- 품절 패턴 분석 → 공급사 안정성 기준 강화

---

## 선택지 B — TikTok 콘텐츠 + 쿠팡 파트너스 (트래픽 루프)

> "TikTok → 쿠팡 파트너스 링크 전환"

### 내용
- TikTok 슬라이드/쇼츠로 상품 바이럴 → 파트너스 링크로 수익화
- 상품 소유 없이 파트너스 커미션만 취하는 구조도 가능
- 현재 보류 중 (OpenAI API 이미지 고도화 필요)

### 장점
- 성공 시 자동 매출 증가 (트래픽 자산 구축)
- 파트너스 구조면 재고/CS 리스크 없음
- 바이럴 상품 1개가 전체 수익을 바꿀 수 있음

### 단점
- 이미지 퀄리티 개선 필요 (OpenAI API 비용 발생)
- TikTok 알고리즘 의존성
- 단기 수익 불확실

### 필요한 것
- OpenAI API 키 발급
- Larry 스킬 이미지 고도화
- TikTok 계정 `today_item_hunt` 운영 전략

## 선택지 C — 특정 카테고리 버티컬 집중

> "잡화 → 한 분야 전문화"

### 후보 버티컬

| 버티컬 | 이유 | 현재 상품 |
|--------|------|----------|
| **임신/육아/파티** | 임밍아웃 2종 성과 있음, 니치 경쟁 낮음 | 임밍아웃 카드/복권 |
| **자동차 용품** | 핸드폰거치대+차량등록증케이스 기보유 | 2건 |
| **뷰티/스킨케어** | 물광퍼프+블랙헤드, 반복구매 가능 | 2건 |
| **완구/선물** | 붕어빵슬라임 56% 마진, TikTok 바이럴 가능 | 1건 |

### 장점
- 카테고리 SEO 상승 (쿠팡 알고리즘이 전문 셀러 선호)
- 소싱/마케팅 효율 증가

### 단점
- 버티컬 선택이 잘못되면 수익 감소
- 리서치 + 초기 세팅 필요

## 선택지 D — AI 자동화 고도화 (시스템 레벨업)

> "더 잘 돌아가는 파이프라인 만들기"

### 내용
- 현재 크론 + 파이프라인 → AI 기반 소싱 추천 엔진
- 도매꾹 트렌드 자동 스캔 → 판매 가능성 점수 → 자동 등록
- 일일 브리핑에서 아이디어 → 자동 소싱 연결

### 장점
- 장기적으로 가장 강력한 구조
- 사람 개입 최소화

### 단점
- 개발 공수 높음
- 단기 수익 없음
