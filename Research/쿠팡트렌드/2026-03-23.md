# 쿠팡 트렌드 분석 — 2026-03-23

🟡 일부 불확실 — 현재 워크스페이스에서 확인 가능한 쿠팡 Seller API는 **내 판매상품 현황 조회는 가능**하지만, 공개 마켓 베스트셀러/급상승 랭킹 API는 확인되지 않았고, 외부 검색 보강용 Brave 키도 미설정이라 이번 리포트는 **쿠팡 API + 기존 vault 리포트 + 내부 상품 포트폴리오 증거** 중심으로 작성함.

## 이번 주 핵심 결론
- **강한 축은 여전히 리빙/정리/주방**이다.
- 2월 말에 포착된 `수납`, `요가매트`, `법랑냄비`, `주방 보조도구` 계열 신호는 아직 완전히 꺼진 흐름이 아니다.
- 다만 **현재 Seller API 실판매 10개는 더 좁게 수렴**했다: `전자레인지 찜기`, `커튼링/집게고리`, `압축봉`처럼 **생활밀착·설치간단·저리스크 리빙** 쪽이다.
- 즉, 이번 주 소싱 판단은 **"리빙 안에서도 설치형/정리형/주방 간편조리형으로 더 압축"** 하는 쪽이 맞다.

### 1) 2월 하순 → 3월 하순: "넓은 생활 트렌드"에서 "설치형 리빙"으로 수렴
- **2026-02-21**: 텀블러, 수납, 요가매트, 법랑냄비, 싱크대 휴지통, 틈새수납장 등 **후보 폭이 넓었음**.
- **2026-02-22**: 텀블러, 요가매트, 수납, 5단선반, 멀티뚜껑, 양념통, 법랑냄비 등 **리빙/주방 실용템 집중**이 강화됨.
- **2026-03-23 현재 Seller API 실상품 10개**: 전자레인지 찜기 2종, 집게고리/커튼링 5종, 압축봉 3종으로 **실제 운영 SKU는 더 좁고 선명한 리빙 생활형**으로 압축됨.

### 2) 유지되는 축
- `수납/정리`
- `주방 실용`
- `운동/홈트`

이 3축은 2월 리포트와 현재 실판매 구조 모두에서 반복된다.

### 3) 약해진 축
- 2월에 보였던 `텀블러`, `투명보틀`, `깔때기`, `장갑` 같은 범용 소형 소모형은 이번 주 현재 Seller API 실판매 10개 기준으로는 전면에 없다.
- 즉, 단순 범용 소품보다 **설치/정리/조리처럼 사용 맥락이 명확한 상품**이 우선순위로 올라간 상태로 읽힌다.

## 🏪 우리 카테고리 경쟁 현황

> 기준: 현재 실판매 10개(API), 2026-02-28 등록상품 현황(vault), 운영자가 제공한 현재 등록 22개 카테고리 메모(임밍아웃/뷰티/IT액세서리/완구 포함)

### 1) 리빙/수납/주방
- **경쟁 강도: 높음**
- 이유: 이미 우리 포트폴리오가 이쪽으로 깊게 들어와 있고, 외부 시장에서도 가장 흔한 범용 영역.
- 틈새 포인트:
  - 단품보다 **세트/번들**
  - `압축봉+커튼링`, `찜기+라면용기`, `정리함+칸막이`처럼 **사용 시나리오 결합형**
  - 사진/상세에서 **설치 전후**, **수납 전후**, **전자레인지 조리 예시**를 강하게 보여주는 방식

### 2) 임밍아웃
- **경쟁 강도: 중간~높음**
- 과거 경쟁 리포트에서 `임밍아웃 복권포스터` 가격 과대 이슈가 있었음.
- 틈새 포인트:
  - 이벤트성이라 시즌/감정 맥락은 좋지만, **가격 민감도 높고 카피 차별화 어려움**
  - 단일 아이템보다 **포스터+소품 세트** 같은 구성형이 유리

### 3) 뷰티
- **경쟁 강도: 매우 높음**
- 뷰티는 검색량이 커도 브랜드/리뷰/신뢰 문제가 커서 초보 셀러가 밀리기 쉬움.
- 틈새 포인트:
  - 화장품 본품보다 **뷰티 보조도구/정리도구** 쪽이 더 안전
  - 인증/브랜드 민감도가 낮은 소도구 위주가 낫다

### 4) IT 액세서리
- **경쟁 강도: 매우 높음**
- 과거 포트폴리오에서도 충전기/이어폰류는 있었지만 가격 경쟁이 극심함.
- 틈새 포인트:
  - 범용 케이블/이어폰보다 **정리형 액세서리**, **책상 정리 결합형**이 낫다
  - 즉, IT 그 자체보다 **리빙과 섞인 IT 정리 카테고리**가 현실적

### 5) 완구
- **경쟁 강도: 중간**
- 시즌/연령/브랜드 영향을 크게 받음.
- 틈새 포인트:
  - 유행 캐릭터 직접 경쟁보다 **비브랜드 조립·보관·정리 연계형**이 안전
  - 다만 현재 확보된 근거 데이터는 약하므로 이번 주 최우선 카테고리는 아님
