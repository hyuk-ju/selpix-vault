# AI 블로그 자동화 SaaS

> GPT로 SEO 블로그 자동 생성 월정액

## 배경
키워드 입력하면 SEO 최적화된 블로그 포스트를 자동 생성하는 SaaS. 월 $19 구독.

---

## 시장 분석 (trend-scout)
- **수요:** AI 콘텐츠 생성 수요 폭발적 성장
- **경쟁:** Jasper, Copy.ai 등 선두 주자 다수
- **타이밍:** 후발 주자로 차별화 필수
- **판정:** 보류 — 레드오션이나 한국어 특화 니치 가능

## 기술 분석 (ops-dev)
- **실현 가능성:** GPT API + Next.js로 2주 MVP 가능
- **MVP 범위:** 키워드 입력 → 블로그 1편 생성
- **추가 개발:** SEO 분석 모듈, 워드프레스 퍼블리싱 API
- **판정:** 추천 — 기술적 진입장벽 낮음

## 비즈니스 분석 (biz-writer)
- **수익 모델:** $19/월 (개인), $49/월 (팀)
- **예상 KPI:** 월 유료 100명 목표
- **판정:** 추천 — 낮은 초기 비용, 반복 수익 모델

## 7일 실행안
| 기간 | 내용 |
|------|------|
| Day1 | 경쟁사 5개 기능 비교표 작성 |
| Day2-3 | MVP 프로토타입 + GPT 프롬프트 설계 |
| Day4-7 | 랜딩페이지 + 베타 신청 폼 |

## 악마의 변호인 (main)
> 의도적으로 반대 근거를 찾아 검증한 결과

- **치명적 결함:** Google이 AI 콘텐츠 패널티 강화하면 핵심 가치 소멸
- **시장 리스크:** 한국어 시장 규모가 글로벌 대비 1/50
- **실행 리스크:** SEO 품질이 GPT 기본 출력으로는 부족
- **유사 실패 사례:** AI Writer 스타트업 80%가 1년 내 피벗
- **판정:** 보류 — Google 패널티 리스크 + 시장 규모 우려

## 종합 판정
**✅ 추천 (주의 필요)**

> 판정 규칙: 3인 분석 + 악마의 변호인. critic이 반대하면 최종 판정 1단계 하향.
