# AI 블로그 자동화 SaaS

> GPT로 SEO 블로그 자동 생성 월정액

## 배경
키워드 입력하면 SEO 최적화된 블로그 포스트를 자동 생성하는 SaaS. 월 $19 구독.

---

## 시장 분석 (trend-scout)
- **수요:** 쿠팡 셀러 100만명+, 상품 설명문 작성이 최대 고충
- **경쟁:** 셀러노트(월 3.9만원) 정도, 경쟁 약함
- **타이밍:** 적절 — AI 상품 설명 수요 시작 단계
- **판정:** 추천 — 명확한 타겟 + 경쟁 부재

## 기술 분석 (ops-dev)
- **실현 가능성:** 기존 coupang_api.js 활용 가능
- **MVP 범위:** 상품명+이미지→SEO 설명문 생성
- **추가 개발:** GPT 프롬프트 + 쿠팡 카테고리별 템플릿
- **판정:** 추천 — 기존 인프라 재활용으로 빠른 개발

## 비즈니스 분석 (biz-writer)
- **수익 모델:** 월 1.9만원 (100건/월), 3.9만원 (무제한)
- **예상 KPI:** 월 유료 200명 목표
- **판정:** 추천 — 높은 반복 수익 + 낮은 이탈률 예상

## 7일 실행안
| 기간 | 내용 |
|------|------|
| Day1 | 쿠팡 셀러 커뮤니티 수요 조사 |
| Day2-3 | GPT 프롬프트 10개 카테고리 테스트 |
| Day4-7 | MVP + 네이버 카페 홍보 |

## 악마의 변호인 (main)
> 의도적으로 반대 근거를 찾아 검증한 결과

- **치명적 결함:** 쿠팡이 자체 AI 설명 도구 출시 시 경쟁력 소멸
- **시장 리스크:** 셀러 유료 전환 의지 불확실
- **실행 리스크:** 카테고리별 품질 차이가 클 수 있음
- **유사 실패 사례:** 아마존 셀러 도구들의 고객 획득 비용 높았음
- **판정:** 추천 — 피벗 방향이 원래보다 확실히 낫고, 리스크 관리 가능
