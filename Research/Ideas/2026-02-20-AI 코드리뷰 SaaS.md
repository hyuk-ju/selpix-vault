# AI 코드리뷰 SaaS

> GitHub PR 자동 리뷰 월정액 서비스

## 배경
GPT 기반 PR 코드리뷰를 자동화하고 월 $29 구독 모델로 판매. 개인 개발자 타겟.

---

## 시장 분석 (trend-scout)
- **수요:** 코드리뷰 자동화 수요 급증 (GitHub Copilot 효과)
- **경쟁:** CodeRabbit, Sourcery 등 경쟁자 다수
- **타이밍:** 시장 과열기 — 차별화 필수
- **판정:** 보류 — 경쟁 과열로 차별화 없이는 수익 어려움

## 기술 분석 (ops-dev)
- **실현 가능성:** GitHub App + GPT API로 MVP 2주 내 가능
- **MVP 범위:** PR diff 분석 + 코멘트 자동 생성
- **추가 개발:** GitHub Webhook 서버, GPT 프롬프트 튜닝
- **판정:** 추천 — 기술적으로 빠른 MVP 가능

## 비즈니스 분석 (biz-writer)
- **수익 모델:** (분석 불가)
- **예상 KPI:** 월 유료 전환 50명 목표
- **판정:** 추천 — 구독 모델 수익성 확보 가능

## 7일 실행안
| 기간 | 내용 |
|------|------|
| Day1 | 경쟁사 분석 + 차별화 포인트 정리 |
| Day2-3 | GitHub App MVP + GPT 프롬프트 설계 |
| Day4-7 | 베타 배포 + 개발자 커뮤니티 마케팅 |

## 악마의 변호인 (main)
> 의도적으로 반대 근거를 찾아 검증한 결과

- **치명적 결함:** GitHub Copilot이 네이티브 리뷰 기능 추가하면 즉사
- **시장 리스크:** 개인 개발자 유료 전환율 극히 낮음 (1-2%)
- **실행 리스크:** GPT 할루시네이션으로 잘못된 리뷰 생성 시 신뢰 붕괴
- **유사 실패 사례:** DeepCode (Snyk에 인수), Codacy (피벗 반복)
- **판정:** 반대 — 레드오션 + 플랫폼 종속 리스크가 치명적

## 종합 판정
**⏸️ 보류 (리스크 검토 필요)**
