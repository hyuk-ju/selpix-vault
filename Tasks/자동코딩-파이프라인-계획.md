# 자동 코딩 파이프라인 계획

> OpenClaw 에이전트가 아이디어 → 사업계획서 → 코딩까지 자동으로 처리하도록 확장

---

## 배경

현재 `trigger_bkit_coding.js`가 PDCA Plan/Design 문서를 생성한 후 텔레그램에 "Claude Code에서 `/pdca do` 실행하세요"라고 안내. **수동 실행 필요**한 구조.

**목표**: "코딩 착수" 버튼 클릭 후 OpenClaw 에이전트(ops-dev)가 **자동으로 코드를 구현**하도록 변경. 수동 경로(Claude Code CLI)도 유지.

---

## 전체 흐름

```
텔레그램 "🔨 코딩 착수" 버튼
  → process_idea.js --code ID
    → trigger_bkit_coding.js --trigger ID (Plan/Design 생성)
      → run_coding_execution.js --init ID (★ NEW)
        → coding_steps.json 생성 (스텝 분해)
        → codeStatus: "coding_active"
        → 텔레그램: "자동 코딩 시작! N개 스텝"

[매 2시간: coding-execution-loop 크론잡]
  → --list-active → 활성 프로젝트 발견
  → --next PROJECT → 다음 pending 스텝
  → --instruction PROJECT STEP → ops-dev용 지시 파일 생성
  → sessions_spawn → ops-dev 코딩 실행
  → --complete 또는 --fail → 결과 기록 + 텔레그램 알림
  → 전체 완료 시 → codeStatus: "coding_done"
```

---

## 구현할 것 (5단계)

### 1단계: `run_coding_execution.js` 작성 (핵심, ~500줄)

코딩 실행 오케스트레이터. CLI:

| 명령 | 기능 |
|------|------|
| `--init IDEA_ID` | bizplan의 coding_spec → coding_steps.json 생성 |
| `--list-active` | 활성 코딩 프로젝트 목록 |
| `--next PROJECT` | 다음 pending 스텝 정보 JSON |
| `--instruction PROJECT STEP_ID` | ops-dev용 지시 파일(current_task.md) 생성 |
| `--complete PROJECT STEP_ID` | 스텝 완료 + 검증 + 텔레그램 |
| `--fail PROJECT STEP_ID "MSG"` | 스텝 실패 기록 (재시도 or 차단) |
| `--skip PROJECT STEP_ID` | 스텝 건너뛰기 |
| `--status PROJECT` | 프로젝트 코딩 현황 |

#### 스텝 분해 알고리즘

coding_spec에서 자동 분해:
1. **step-0: 프로젝트 초기화** — package.json, 디렉토리 구조
2. **step-1: DB 스키마** — data_model.entities → SQLite 마이그레이션
3. **step-2~N: 기능별** — features 각각 1스텝
4. **step-N+1: 통합 테스트** — smoke test
5. **step-N+2: README** — 문서화

#### coding_steps.json 스키마

```json
{
  "projectName": "openclaw-crm",
  "ideaId": "625bb4f7",
  "projectDir": "projects/openclaw-crm",
  "techStack": "Node.js + SQLite + Telegram Bot API",
  "status": "active",
  "totalSteps": 12,
  "completedSteps": 0,
  "steps": [{
    "stepId": "step-0-project-init",
    "index": 0,
    "title": "프로젝트 초기화",
    "description": "package.json, 디렉토리 구조, 의존성 설치",
    "sourceSpec": {},
    "acceptance": ["ls {projectDir}/package.json"],
    "status": "pending",
    "attempts": 0,
    "maxAttempts": 3,
    "error": null,
    "filesCreated": []
  }]
}
```

### 2단계: `trigger_bkit_coding.js` 수정

- `triggerCoding()` 끝에 `run_coding_execution.js --init` 호출 추가
- 텔레그램 메시지 변경:
  - ~~"Claude Code에서 시작"~~ → "자동 코딩 시작 예정" + 수동 경로도 안내

### 3단계: `coding-execution-loop` 크론잡 추가 (jobs.json)

| 항목 | 값 |
|------|-----|
| 주기 | 매 2시간 |
| 에이전트 | main → ops-dev (sessions_spawn) |
| 타임아웃 | 1200초 (20분) |
| 최대 스텝/세션 | 2개 |

크론잡 메시지:
1. `--list-active`로 활성 프로젝트 확인
2. `--next`로 다음 스텝 확인
3. `--instruction`으로 ops-dev용 지시 파일 생성
4. `sessions_spawn → ops-dev`에게 위임
5. 결과 검증 후 `--complete` 또는 `--fail`

### 4단계: 625bb4f7로 E2E 테스트

기존 테스트 데이터(CRM 아이디어)로 전체 흐름 검증

### 5단계: 문서 동기화

- AGENTS.md: coding-execution-loop + 콜백 문서화
- SYSTEM_STATE.md: 코딩 실행 섹션 추가
- CLAUDE.md: run_coding_execution.js 파일 추가
- 변경로그: 기록

## 에러 처리

- **스텝 실패**: attempts++ → 최대 3회 재시도 (에러 메시지 포함)
- **3회 실패**: `codeStatus: "coding_blocked"` → 텔레그램 `[재시도] [건너뛰기] [중단]` 버튼
- **7일 무진행**: 경고 알림 + 자동 일시 중지

---

## 텔레그램 알림

| 상황 | 메시지 |
|------|--------|
| 스텝 완료 | 🔨 코딩 진행 — {project} (3/12) ✅ Step 2 완료 |
| 스텝 실패 | ⚠️ 코딩 실패 — {project} (Step 3, 시도 2/3) |
| 전체 완료 | 🎉 코딩 완료! [✅ 검증 완료] [🔄 재코딩] |
| 차단 | 🚨 코딩 중단 [🔄 재시도] [⏭ 건너뛰기] |

## 상태 전이

```
triggered → coding_active → coding_done → verified
                  ↓
            coding_blocked (3회 실패)
```

## 수동 경로 (폴백)

자동 코딩과 별개로 Claude Code CLI에서도 실행 가능:
```bash
cd projects/openclaw-crm && /pdca do openclaw-crm
```
Plan/Design 문서가 그대로 있으므로 수동으로도 작동.
