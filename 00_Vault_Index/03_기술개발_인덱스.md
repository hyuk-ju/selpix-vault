## 1. Selpix 기술 아키텍처

### 1-1. 현재 기술 스택

| 레이어 | 기술 | 용도 |
|--------|------|------|
| 프론트엔드 | Next.js, React, TypeScript, Tailwind CSS | 웹 UI |
| 백엔드 | FastAPI (Python) | API 서버, 자동화 로직 |
| DB | MySQL | 상품/주문/사용자 데이터 |
| 호스팅 | Google Cloud VM + Cloudflare Worker | 배포 및 HTTPS 프록시 |
| AI | GPT 기반 (파인튜닝 포함) | 콘텐츠 생성, 상품 추천 |
| 외부 API | 쿠팡 Open API, 도매꾹 Private API | 상품 등록·발주·데이터 수집 |

### 1-2. 핵심 모듈 (6개)

1. **상품 소싱 자동화** — 도매꾹/1688 상품 데이터 수집 → AI 기반 추천 (검색량, 경쟁도, 마진 기반)
2. **마진 분석 엔진** — 판매가·도매가·수수료·배송비·광고비·보관비 기반 자동 계산. 마진율/순이익/ROAS 실시간 산출
3. **콘텐츠 자동 생성** — GPT 기반 상세페이지 텍스트, SEO 태그, USP 5개 자동 추출
4. **SNS 영상 생성** — 마케팅용 숏폼 비디오 자동 생성
5. **자동 이행(Fulfillment)** — 주문 발생 → 도매꾹 API 자동 발주 → 송장번호 수집 → 쿠팡 반영
6. **쿠팡 상품 등록** — 쿠팡 Open API로 제목/옵션/이미지/상세설명 자동 등록

## 2. 외주 개발 스펙 (Wishket RFD)

### 2-1. 프로젝트 개요

- **프로젝트명**: Selpix 자동화 커머스 플랫폼
- **예산**: 320만원 (±20%)
- **개발 기간**: 30일
- **작성일**: 2025-10-27
- **작성자**: 유민우, 이혁주
- **용도**: 위시켓 클라이언트 프로젝트 등록용 RFD

### 2-2. 기능별 예산 배분

| 항목 | 예상 금액 | 기간 |
|------|----------|------|
| 프론트엔드 (UI) | 80만원 | 7일 |
| 백엔드 (API, 자동발주) | 120만원 | 10일 |
| 데이터베이스 구축 | 50만원 | 5일 |
| 대시보드 및 통합 테스트 | 70만원 | 8일 |
| **합계** | **320만원** | **30일** |

### 2-3. RFD 핵심 기능 상세

**A. 상품 자동 등록**
- 쿠팡 Open API → 상품 정보 자동 등록 (제목, 옵션, 이미지, 상세설명)
- 도매꾹 API → 상품 데이터 수집 및 DB 저장
- 자동 필터링: 불량 데이터(공백, 특수문자) 제거
- 유사도 기반 상품 매칭 알고리즘 (쿠팡↔도매꾹)

**B. 자동 발주 시스템**
- 주문 발생 → 도매꾹 주문 API 자동 호출
- 고객 주소/수량/옵션 자동 전달
- 송장번호 자동 수집 → 쿠팡 API 반영
- 발주 실패 시 관리자 알림 (Discord Webhook)

**C. 마진 계산 자동화**
- `순이익 = 판매가 - (도매가 + 수수료 + 배송비 + 광고비 + 보관비)`
- 수수료율/배송비 등 설정값 변경 가능
- 예상 수익률, 마진율 실시간 표시

**D. 관리자 대시보드**
- 전체 주문 현황, 발주 상태, 오류 로그 시각화
- 상품별 판매량·수익 통계, ROI/ROAS
- 자동화 로그 확인 및 수동 재처리

### 2-4. 연동 구성도

```
[사용자] → index.html → 백엔드(자동발주.py) → 쿠팡/도매꾹 API → DB → 대시보드
```

### 2-5. 기대효과
- 인력 없이 주문 → 발주 → 정산 자동화
- 수동 오류 및 재고 실수 90% 감소
- 실시간 수익 분석 기반 판매 전략 최적화

## 4. Selpix 2.0 전략 — 데모마켓 + 교육 시스템

### 4-1. 배경: Selpix 1.0의 구조적 한계

- Selpix 1.0은 "운영 자동화 SaaS" — 이미 결정된 상품의 반복 업무 자동화
- **해결하지 못하는 문제**: 초보 셀러의 초기 실패율 (60~70% 1년 내 이탈)
- **핵심 원인**: "상품력·시장성을 사전 검증할 시스템이 없다"
- 상품 선택 → 시장성 미검증 → 광고비 소진 → 3~6개월 내 포기

### 4-2. 데모마켓 컨셉

- **쿠팡 유사 UI**의 시뮬레이션 마켓 (실제 거래 없음, 교육용)
- 수강생이 도매 상품을 선택 → Selpix로 상세페이지/키워드/가격 구성 → 데모마켓에 업로드
- 다른 참여자가 **가상 포인트**로 탐색·클릭·가상 구매
- "구매하고 싶은 이유" / "구매가 꺼려지는 이유" 피드백 수집

### 4-3. 데이터 수집 항목

| 데이터 유형 | 상세 |
|------------|------|
| 행동 데이터 | 클릭 수, 조회수, 장바구니(가상), 구매 의사, 이탈 |
| 가격 반응 | 가격 변동에 따른 선택률 변화 |
| 콘텐츠 평가 | 이미지 신뢰도, 상세페이지 설득력, 키워드 매칭 |
| 카테고리 경쟁도 | 카테고리별 선택률 비교 |
| 사용자 유형별 | 초보/중급 셀러의 선택 기준 차이 |

### 4-4. 데이터 활용 (AI 연결)

1. **상품력 스코어 모델** — 여러 지표 기반 점수화
2. **시장성 예측 모델** — 카테고리별/가격대별 성공 확률
3. **AI 추천 고도화** — 우선순위/추천 순서에 데모마켓 데이터 반영
4. **키워드/가격 제안** — 실제 사용자 반응 기반 최적화

### 4-5. 수익 모델 3단계

| 단계 | 수익원 |
|------|--------|
| 단기 | 교육 참여비 + Selpix 구독 + 데모마켓 프리미엄 기능 |
| 중기 | 도매/플랫폼 제휴 수수료 + B2B 데이터/리포트 판매 |
| 장기 | AI 상품력/시장성 예측 서비스 + 리테일 미디어 협업 |

### 4-6. Selpix 최종 포지션

> **"초보 셀러 실패율 감소 + 상품력·시장성 검증 + 운영 자동화"를 한 번에 제공하는 커머스 OS**

- 교육(이론) → 실습(데모마켓) → 피드백(평가) → 데이터 축적 → AI 모델 → 자동화
- 기존 서비스(교육만, SaaS만, 도매만)와 달리 **전 과정 통합**

### 4-7. 법적 리스크 인식

- 쿠팡 유사 UI: 레이아웃/패턴 수준 참고는 합법, 상표/로고 사용 불가
- 데모마켓은 가상 포인트 기반 비실거래 → 전자상거래법 적용 외
- 데이터 수집: 비식별 처리 + 교육 목적 범위 명시 필요
- IP: 시스템·알고리즘 특허출원 검토 대상
