## Selpix 기술 스택 요약

### 현재 구현

| 항목 | 기술 |
|------|------|
| 프론트엔드 | Next.js, React, TypeScript, Tailwind CSS |
| 백엔드 | FastAPI (Python) |
| DB | MySQL |
| 호스팅 | Google Cloud |
| AI | GPT 기반 콘텐츠 생성, LLM 파인튜닝 |
| 외부 API | 쿠팡 API, 도매꾹(Domaggok) API |

### 핵심 모듈

1. **상품 소싱 자동화** — AI 기반 상품 추천
2. **마진 분석 엔진** — 자동 마진/ROAS 계산
3. **콘텐츠 자동 생성** — GPT 기반 상세페이지, SEO 태그
4. **SNS 영상 생성** — 마케팅용 비디오 자동 생성
5. **자동 이행(Fulfillment)** — 주문 처리 자동화
6. **쿠팡 상품 등록** — API 기반 자동 등록
