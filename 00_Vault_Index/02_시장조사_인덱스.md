## 1. 타겟 고객 세그먼트

### 1-1. WTP(지불의향) 기반 고객 분류

| 세그먼트 | WTP (월) | 특성 | Selpix 전략 |
|----------|----------|------|-------------|
| 완전 초보 셀러 | 0~1만원 | 엑셀도 어려움, 무료 도구 선호 | 프리미엄 미끼 → 전환 유도 |
| 경험 1년 미만 | 1~3만원 | 상품 소싱에 가장 큰 고통 | **핵심 타겟** — 19,900원 SaaS |
| 월 매출 500만+ 셀러 | 3~10만원 | 자동화·시간 절약에 돈 지불 | 고급 기능 업셀 대상 |
| B2B (소규모 브랜드) | 10만원+ | 다채널 관리, 재고 통합 필요 | 중장기 B2B 모델 |

### 1-2. 국내 셀러 규모

- **쿠팡 마켓플레이스 셀러**: 약 54.3만 명+
- **네이버 스마트스토어**: 약 70만 개 이상 활성 스토어
- **연간 신규 진입 셀러**: 약 7만 명 (증가 추세)
- **초보 셀러 중 1년 내 이탈률**: 약 60~70% (핵심 pain point)

## 2. Unit Economics & 수익 모델

### 2-1. 핵심 지표 설계

| 지표 | 목표값 | 비고 |
|------|--------|------|
| ARPU | 19,900원/월 | 기본 구독 단가 |
| CAC (고객획득비) | 50,000원 이하 | 콘텐츠 마케팅 + 커뮤니티 |
| LTV | 239,000원 (12개월 기준) | 월 이탈률 8% 가정 시 |
| LTV/CAC 비율 | 4.8x | 최소 3x 이상 유지 필요 |
| BEP 시점 | 월 유료 구독 2,500명 | 고정비 감안 |
| Churn Rate (월) | 8~10% 목표 | 업계 평균 ~15% |

### 2-2. 비용 구조 이슈 ⚠️

**LLM 비용 vs 가격 괴리** (질문.txt 핵심 지적):
- GPT-4 파인튜닝 + API 콜 비용이 사용자당 월 5,000~15,000원 발생 가능
- 19,900원 가격에서 인프라(서버, DB, API) 빼면 **마진이 거의 없거나 역마진**
- **해결 방향**: 티어별 AI 사용량 제한 (기본 100회/월, 프로 무제한), 캐싱 전략으로 중복 호출 절감

### 2-3. 프리미엄 전환 전략

- Freemium → 유료 전환율 목표: 5~8%
- 무료 티어: 상품 분석 3개/일, 마진 계산기
- 유료 티어: 무제한 분석, 자동 등록, 콘텐츠 생성
- NPS 60+ 달성 시 자연 바이럴 기대

## 5. 플랫폼 리스크 분석

### 5-1. 쿠팡 알고리즘 편향

- 쿠팡 자체 로켓배송 상품이 검색 상위 노출에서 구조적 우위
- 마켓플레이스 셀러는 **광고비 지출 없이는 노출 극히 제한적**
- 쿠팡 광고 매출: 수천억 원 규모 → 셀러의 광고비 의존도 높음
- 공정거래위원회 과징금: 약 1,408억 원 (알고리즘 편향 관련)

### 5-2. 셀러 실패 구조

- 셀러가 광고비를 쏟아도 실패 → 그 광고비가 플랫폼 매출이 되는 구조
- "셀러의 실패가 플랫폼의 이익" 이라는 구조적 문제
- **Selpix 포지셔닝 기회**: "광고비 누수 방지" 프레이밍이 "시간 단축"보다 효과적

### 5-3. API 의존 리스크

- 쿠팡 API 정책 변경 시 핵심 기능 마비 가능
- 도매꾹 API 독점 계약도 갱신 리스크 존재
- **대응 전략**: 멀티 소싱 채널 확보 (네이버, 11번가 등)

## 10. 사업계획서 비판적 검토 (핵심 피드백)

`질문.txt` 기반 — 사업계획서 자체 검증 결과:

### 10-1. 경쟁사 비교의 오류
- 초보 셀러가 실제로 비교하는 대상은 사방넷이 아니라 **엑셀/구글 시트**
- "사방넷 대비 저렴" 프레이밍은 타겟 고객의 현실과 불일치
- **수정 방향**: "수작업 대비 자동화 가치" 로 리프레이밍

### 10-2. LLM 비용-수익 괴리
- GPT-4 파인튜닝 + 인퍼런스 비용이 월 구독 19,900원과 맞지 않음
- **해결책**: 티어별 AI 사용 제한, 경량 모델(GPT-3.5/오픈소스) 혼용, 캐싱

### 10-3. B2B 영업 역량 부족
- 현 팀 구성에 세일즈/마케팅 전문 인력 없음
- 기술 중심 팀으로 고객 획득 전략이 약함
- **보완**: 커뮤니티 기반 자연 유입 + 콘텐츠 마케팅에 집중

### 10-4. 도매꾹 Private API — 기술적 해자 (MOAT)
- 도매꾹과의 Private API 접근이 **가장 강력한 차별화 요소**
- 경쟁사는 도매꾹 데이터에 직접 접근 불가
- **전략**: 이 기술적 해자를 사업계획서 전면에 배치

### 10-5. 매출 전망 현실성
- 매출 전망치가 과대 추정될 가능성 있음
- Unit Economics 재검증 필요 (특히 churn rate와 CAC)
- **권장**: 보수적/중립적/낙관적 3개 시나리오로 제시
