## 4. 활용 가이드

### 4-1. 마케팅 콘텐츠 제작 시

- **숏폼 (릴스/쇼츠)**: 완성 영상에서 15~60초 클립 추출, 후킹 변경 버전 참고
- **SNS 썸네일**: 팀 사진 + 사업자료 사진 활용
- **데모 영상**: Selpix 시스템 캡처 (`01_Assets/03_증빙자료/`) + 효과음 조합
- **IR 발표**: `문제 인식.pdf` + 영상 하이라이트 클립

### 4-2. 파일 관리 권장사항

- MOV 원본은 용량이 크므로 편집 후 별도 백업 권장
- HEIC 사진은 SNS/문서 사용 시 JPG 변환 필요
- 완성 영상 네이밍 통일 권장: `Selpix_마케팅_v01.mp4` 형식
