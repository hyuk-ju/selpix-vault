## 1. 쿠팡 마켓플레이스 현황

### 1-1. 플랫폼 규모

| 지표 | 수치 |
|------|------|
| 월간 활성 사용자 (MAU) | **3,096만 명** |
| 거래액 (2023) | **30조 원+** (매년 20%+ 성장) |
| 판매 방식 | 마켓플레이스, 로켓배송, 로켓그로스 |
| 신규 셀러 첫 매출 | 30%가 5일 이내 첫 매출 달성 |

### 1-2. 수수료 체계 (2025~2026)

#### 기본 수수료 구조

| 항목 | 수수료율 |
|------|----------|
| 상품 판매 수수료 | **4~10.9%** (카테고리별) |
| 서비스 이용 수수료 | 월매출 100만+ 시 55,000원/월 |
| 배송 수수료 | 배송비에 별도 부과 |

> **쿠팡 특징**: 최종 결제금액(쿠폰/할인 적용 후) 기준 수수료 산정 → 셀러에게 비교적 유리

#### 로켓그로스 2025년 변경 사항 (2025.01.06~)

| 변경 항목 | 내용 |
|----------|------|
| 상품 사이즈 구분 | 기존 → **6단계로 세분화** |
| 소형 상품 (30cm 이하, 1kg 미만) | 입고비 150원, 출고비 800원 |
| 무료 보관 기간 | 60일 → **30일로 축소** (2025.04~) |
| 반품 회수·재입고 요금 | **신설** (기존 쿠팡 부담 → 셀러 부담) |
| 반품 무상 제공 | 월 20건까지 무상 (2026.01까지) |

### 1-3. 2026년 전망 — 비용 재편 예상

**온라인플랫폼규제법 시행에 따른 변화:**

| 변화 영역 | 예상 영향 |
|----------|----------|
| 정산 단축 | 60일 → 30일 가능 (셀러 현금흐름 개선) |
| 수수료 조정 | 정산 단축 보전으로 수수료 인상 가능 |
| 광고 의존도 | 노출 구조 변화로 광고비 증가 예상 |
| 쿠폰/특가 분담 | 프로모션 비용 셀러 분담 확대 |
| 공제·보류 기준 | 강화 가능성 |

**핵심 인사이트:**
> "정산이 빨라지는 '좋은 변화'가 오더라도, 총비용이 함께 오르면 셀러 순이익은 늘지 않을 수 있다"

**셀러 전략 권고:**
- 광고비 상한선 설정 (마진 대비 일정 비율 초과 시 SKU 축소)
- 채널 분산 전략 (쿠팡 의존도 70% 이하 유지)
- "매출이 얼마나 남는가"가 플랫폼 선택 기준으로 이동

## 2. 네이버 스마트스토어 현황

### 2-1. 수수료 대개편 (2025.06.02~)

**기존 구조 → 신규 구조:**

| 구분 | 기존 | 변경 후 |
|------|------|---------|
| 유입 수수료 | 2% (네이버 쇼핑 유입 시) | **폐지** |
| 판매 수수료 | 없음 | **신설 3%** (기본) |
| 판매자 마케팅 수수료 | 없음 | **1%** (마케팅 유입 시) |
| 주문관리 수수료 | 1.98~3.63% (규모별) | 유지 (10월 인하) |

#### 판매 수수료 상세

| 유입 경로 | 수수료 |
|----------|--------|
| 네이버 가격비교, 플러스 스토어 (기본) | **3%** |
| 네이버 광고 (파워링크, 쇼핑검색) | **1%** |
| 외부 마케팅 (SNS, 블로그 — 마케팅 링크 필요) | **0.91%** |

### 2-2. 2025년 10월 추가 인하

- 모든 결제수단의 네이버페이 주문관리 수수료율 인하
- 버티컬·솔루션 사용료 인하
- N배송관(도착보장관): 2% → **0%**

### 2-3. 스타트 제로수수료 변경 (2025.01~)

| 항목 | 내용 |
|------|------|
| 매출연동수수료 | 0% 유지 |
| 주문관리수수료 | **즉시 할인 → 페이백 환급** 방식으로 변경 |
| 환급 한도 | 월 최대 13만원 |

### 2-4. 네이버 커머스 전략 방향

| 전략 | 내용 |
|------|------|
| AI 커머스 | AI 기반 개인화 추천 서비스 강화 |
| 네이버플러스 스토어 | 독립 커머스 앱 출시 → 쿠팡과 직접 경쟁 |
| AI 초개인화 | 사용자 행동 기반 맞춤형 상품 추천 |
| 외부 유입 인센티브 | 마케팅 링크 활용 셀러에게 수수료 우대 |

## 3. 쿠팡 vs 네이버 — 셀러 비용 비교

### 3-1. 시뮬레이션: 월 매출 500만원 셀러 기준

| 비용 항목 | 쿠팡 | 네이버 |
|----------|------|--------|
| 판매 수수료 | ~8% (40만원) | 3% (15만원) |
| 서비스 이용료 | 55,000원/월 | — |
| 주문관리 수수료 | — | ~2.5% (12.5만원) |
| 합계 수수료 | **~45.5만원** | **~27.5만원** |
| 광고비 (평균) | 매출 대비 10~15% | 매출 대비 5~10% |

> ⚠️ 단순 수수료만 보면 네이버가 저렴하나, **쿠팡의 트래픽이 압도적**이므로 노출 대비 실질 비용은 경우에 따라 다름

### 3-2. 수수료 변화 추이

- **쿠팡**: 수수료 자체는 안정적이나, 로켓그로스 물류비 셀러 전가 + 광고 의존도 상승
- **네이버**: 유입 수수료 폐지 → 판매 수수료 신설로 구조 변경. 외부 마케팅 셀러에게 유리한 방향

## 4. Selpix 전략 시사점

### 4-1. 플랫폼별 Selpix 가치 포지셔닝

| 플랫폼 | Selpix 핵심 가치 |
|--------|-----------------|
| **쿠팡** | "광고비 누수 방지" — 알고리즘 분석 + 마진 자동계산으로 수익성 최적화 |
| **네이버** | "외부 유입 전략 자동화" — 마케팅 링크 활용, SEO 키워드 최적화로 수수료 절감 |

### 4-2. 핵심 인사이트

1. **쿠팡 셀러 Pain**: 광고비가 마진을 잡아먹는 구조 → Selpix의 마진 분석이 핵심 가치
2. **네이버 셀러 Pain**: 수수료 구조 복잡해짐 → Selpix의 자동 수수료 계산이 차별화
3. **멀티 채널 관리 수요 증가**: 쿠팡+네이버 동시 운영 셀러가 늘면서 통합 관리 도구 수요 상승
4. **2026 규제 변화 대비**: 정산 단축 + 비용 재편에 대응하는 실시간 수익성 분석 기능 필요
