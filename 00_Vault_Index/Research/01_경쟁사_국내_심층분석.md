## 1. 사방넷 (Sabangnet)

### 1-1. 기업 개요

| 항목 | 내용 |
|------|------|
| 운영사 | 다우기술 (KOSDAQ 상장) |
| 설립 | 이커머스 OMS 분야 국내 최대 |
| 시장 점유율 | OMS 시장 약 80% (2022년 기준) |
| 월 이용료 | 약 20~30만원 (규모별 차등) |
| 핵심 서비스 | OMS (주문관리) + WMS (창고관리) 통합 |

### 1-2. 사방넷 2.0 주요 업데이트 (2025)

2025년 사방넷은 대폭 리뉴얼한 '사방넷 2.0'을 출시했으며, 핵심 변화는 다음과 같음:

**AI 기능 탑재 (사방넷 AI)**
- 쇼핑몰 카테고리 자동 추천
- 상품 연관검색어 자동 추천
- 상품 정보고시 자동 입력
- 셀러 반복 업무를 "3초 만에 처리"한다고 홍보

**통합 관리 확장**
- OMS + WMS 통합 (쇼핑몰-창고 간 재고 실시간 연동)
- 650개 쇼핑몰 연동 지원
- 도매몰/해외몰(중국 등) 연동 강화
- 디지털 보증서 (구매 고객 정품 보증)
- 24시간 AI 챗봇 고객 응대

**SAP 코리아 협업**
- SAP S/4HANA 공급망 관리 시스템과 연동
- 대형 셀러/브랜드 대상 B2B 기능 강화

### 1-3. Selpix 관점 분석

| 관점 | 분석 |
|------|------|
| **위협 요소** | AI 기능 추가로 기존 "AI 없음" 약점이 줄어들고 있음. 카테고리 추천, 검색어 추천 등 Selpix 핵심 기능과 일부 겹침 |
| **여전한 기회** | 월 20~30만원 가격은 초보 셀러에겐 부담. UI 복잡도 문제 여전. 소싱(도매꾹 연동) 기능은 없음 |
| **차별화 포인트** | Selpix는 "소싱→등록→판매→분석"까지 초보 셀러 맞춤. 사방넷은 "이미 판매중인 중급 셀러"를 위한 운영 도구 |
| **주의사항** | 사방넷이 도매 연동을 강화하면 직접 경쟁 가능성 증가. 가격 차별화 + 도매꾹 API 독점이 핵심 방어선 |

## 2. 플레이오토 (Playauto)

### 2-1. 기업 개요

| 항목 | 내용 |
|------|------|
| 운영사 | 커넥트웨이브 (구 코리아센터) |
| 설립 | 2005년 |
| 본사 | 서울 구로구 |
| 직원 수 | 51~200명 |
| 셀러 수 | **23만 셀러** |
| 주요 서비스 | 국내 OMS (플토 2.0, 플토 EMP), 해외 (플토 Global), 일본 (히로게테) |

### 2-2. 서비스 라인업

| 서비스 | 타겟 | 특징 |
|--------|------|------|
| 플토 2.0 | 국내 셀러 | 쇼핑몰 통합관리, 상품수집/재고/주문 |
| 플토 EMP | 대형 셀러 | 기업용 통합 관리 |
| 플토 Global | 해외판매 셀러 | 해외 마켓 연동 |
| 히로게테 | 일본 시장 셀러 | 일본 쇼핑몰 통합관리 |

### 2-3. 최근 동향 (2024~2025)

- 난소프트와 WMS-OMS 연계 전략적 업무협약 체결
- 화해(뷰티 플랫폼)와 커머스 통합 솔루션 연동
- 모듈형 서비스 구조 — 고객이 필요한 기능만 선택 가능
- Google Play 앱 운영 (모바일 관리)

### 2-4. Selpix 관점 분석

| 관점 | 분석 |
|------|------|
| **위협 요소** | 23만 셀러라는 압도적 사용자 기반. 해외 확장(Global, 히로게테)도 진행 중 |
| **여전한 기회** | AI 기능 부재. 소싱/상품 추천 기능 없음. 초보 셀러 특화 기능 없음 |
| **차별화 포인트** | 플레이오토는 "주문 관리 OMS", Selpix는 "소싱+AI 자동화 SaaS" — 카테고리 자체가 다름 |
| **협업 가능성** | 오히려 플레이오토 사용 셀러에게 Selpix를 보완 도구로 제안 가능 (소싱 특화) |

## 3. 윈들리 (Windly)

### 3-1. 기업 개요

| 항목 | 내용 |
|------|------|
| 운영사 | ㈜어베어 (Abear) |
| 설립 | 2021년 |
| 본사 | 서울 강남구 |
| 직원 수 | 약 15명 (2024.01 기준) |
| 누적 고객 | **26,000곳** |
| BEP 달성 | 런칭 3개월 만에 (2022.04) |
| 투자 | 시드 투자 유치 (런칭 4개월 만에) |
| 매출 성장 | 2023년 매출 전년 대비 **4배 이상** 성장 |

### 3-2. 서비스 특징

- **AI 기반** 해외구매대행 상품관리 솔루션
- 상품 소싱 → 상세페이지 제작 → 등록 → 주문관리를 원스톱으로
- 크롬 확장 프로그램: 약 20K 사용자, **4.92점** (764개 리뷰)
- 2023 소비자만족 브랜드 대상 1위 수상

### 3-3. 가격 체계

- 월 약 3.6만원 수준
- 구독 기반 SaaS 모델
- 흑자 성장 기록 중 (시드 투자 이후 지속)

### 3-4. Selpix 관점 분석 ⚠️ 가장 유사한 경쟁자

| 관점 | 분석 |
|------|------|
| **위협 요소** | Selpix와 가장 유사한 포지셔닝. AI 기반, 소싱+등록+관리 원스톱, 초보 셀러 타겟 |
| **핵심 차이** | 윈들리는 **해외구매대행 특화** (아마존, 큐텐, eBay), Selpix는 **국내 마켓 특화** (쿠팡, 네이버) |
| **벤치마크 포인트** | 3개월 BEP, 4개월 투자유치, 15명으로 26,000 고객 → Selpix가 참고할 성장 모델 |
| **전략 시사점** | 윈들리가 국내 시장으로 확장하면 직접 경쟁. 반대로 Selpix가 해외 시장(베트남 등)으로 가면 차별화 유지 |

## 5. 경쟁 포지셔닝 맵

```
                    고가 (20~30만원/월)
                         │
              사방넷 ●    │
                         │
   중급/대형 셀러 ────────┼──────── 초보 셀러
                         │
          플레이오토 ●    │    ● 윈들리(해외)
                         │    ● Selpix(국내) ← 여기
                         │
                    저가 (2~4만원/월)
```

### 핵심 결론

1. **사방넷**: 가장 큰 기존 강자이나 가격/복잡도에서 초보 셀러에겐 진입장벽. AI 추가는 경계 대상.
2. **플레이오토**: 대형 사용자 기반이나 AI/소싱 부재. 보완재 관계 가능.
3. **윈들리**: 가장 유사하지만 해외 특화. 3개월 BEP 벤치마크. 국내 진출 시 직접 경쟁.
4. **Selpix 독보적 차별점**: 도매꾹 Private API + 국내 마켓 특화 + 초보 셀러 UX + 19,900원 가격
