| 항목 | 내용 |

| 설립 | 2015년 |

| 투자 유치 | $110M (Growth Equity, Summit Partners) |

| Trustpilot 평점 | 4.8/5.0 |
| 크롬 확장 평점 | 3.8/5.0 |

### 1-2. 핵심 기능

- **Product Database**: 아마존 상품 검색 및 필터링 (매출, 리뷰, 가격 기반)
- **Keyword Scout**: 키워드 검색량, 추천 입찰가, 트렌드 분석
- **Sales Analytics**: 매출 추정, 이력 추적, 경쟁사 모니터링
- **Listing Builder**: SEO 최적화 리스팅 생성
- **Review Automation**: 리뷰 요청 자동화
- **Supplier Database**: 글로벌 공급업체 검색 (Alibaba 연동)

### 1-3. 가격 체계 (2026)

| 플랜 | 월 가격 (연간) | 핵심 기능 |
|------|---------------|----------|
| Starter | $29/월 | 기본 리서치 |
| Growth Accelerator | $49/월 | 전체 기능 |
| Brand Owner + CI | $99/월 | 브랜드 분석, 경쟁 인텔 |

### 1-4. 최근 동향

- 직원 수 감소 추세 — 수익성 중심 전환으로 보임
- Viral Launch 폐업으로 시장 점유율 확대 기회

## 2. Helium 10 (미국)

### 2-1. 기업 개요

| 항목 | 내용 |
|------|------|
| 매출 | $5~25M 추정 (Owler) |
| 사용자 | **200만+ 활성 사용자** (2022년 돌파) |
| 기업 고객 | 1,051개 기업이 분석/BI 플랫폼으로 채택 |
| 지역 분포 | 미국 54.64%, 인도 12.68%, 영국 8.63% |
| Trustpilot 평점 | 2.7/5.0 (최근 하락) |
| 크롬 확장 평점 | 4.2/5.0 |

### 2-2. 핵심 기능 (30+ 도구)

- **Cerebro**: 역방향 ASIN 검색 (경쟁사 키워드 발굴)
- **Magnet**: 키워드 리서치
- **Black Box**: 상품 발굴 (필터 기반)
- **Profits**: 실시간 수익 대시보드
- **Listing Builder**: AI 기반 리스팅 최적화
- **Market Tracker**: 시장/카테고리 추적
- **Adtomic**: PPC 광고 자동화
- **Refund Genie**: FBA 환불 자동 청구

### 2-3. 정확도 비교 (vs Jungle Scout)

| 지표 | Helium 10 | Jungle Scout |
|------|-----------|-------------|
| 정확한 매출 예측 비율 | **29.5%** | 15.9% |
| 평균 오차 (단위) | **22단위** | 35단위 |
| 결론 | 매출 예측 약 10% 더 정확 | — |

### 2-4. 2026년 주요 변화

- **가격 인상**: 2026.01 가격 인상 단행 → 사용자 반발, 전체 평점 4.8 → 4.3 하락
- **Starter 플랜 폐지**: 신규 가입자에게 Starter 플랜 미제공 → 초보 셀러 진입장벽 상승
- Viral Launch 폐업으로 이탈 셀러 흡수 중

## 6. Selpix 글로벌 포지셔닝 시사점

### 6-1. 벤치마크 모델

| 모델 | 벤치마크 포인트 | Selpix 적용 |
|------|---------------|-------------|
| Jungle Scout | 상품 리서치 → 등록까지 확장 | 도매꾹 소싱 → 쿠팡 등록 자동화 |
| ZIK Analytics | 저가 + 특정 플랫폼 특화 | 19,900원 + 쿠팡/네이버 특화 |
| 윈들리 | 3개월 BEP + 소규모 팀 | 린스타트업 모델 벤치마크 |
| Dianxiaomi | 대규모 사용자 → 데이터 플라이휠 | 데모마켓 데이터 수집 전략 |

### 6-2. 글로벌 트렌드에서 Selpix 기회

1. **AI 가격 경쟁 심화**: 해외 도구들이 $29~$99 → Selpix의 $14(19,900원)는 가격 파괴적
2. **플랫폼 특화 트렌드**: 아마존 특화 도구가 성공 → 쿠팡 특화도 유효한 전략
3. **동남아 확장 기회**: 글로벌 도구들이 아마존 중심 → 쿠팡/Shopee 공백을 Selpix가 채울 수 있음
4. **통합 AI 기능**: 소싱+등록+분석+콘텐츠 생성을 한 곳에서 → 해외 도구도 이 방향으로 이동 중
