## OpenClaw Browser Relay

### 개요
OpenClaw이 **네 크롬 브라우저 탭을 직접 제어**하는 크롬 확장 프로그램.
로그인된 세션 그대로 사용 가능 → WAF 있는 사이트도 접근 가능.

### 아키텍처 (검증 완료)
```
사무실 서버 (OpenClaw)
    ↓ wss:// (Tailscale Serve HTTPS)
윈도우 Gateway (포트 18789, bind: lan)
    ↓
CDP Relay Server (포트 18792)
    ↓ WebSocket
Chrome 확장 (Browser Relay, 로컬 빌드)
    ↓ chrome.debugger API
실제 크롬 탭
```

### 연결 정보
- 윈도우 Tailscale: `100.113.239.15` / `desktop-ir43sud`
- Tailscale Serve: `https://desktop-ir43sud.tail39cdea.ts.net`
- Gateway Token: `fcc0dfdd43df45229bfe4d7f704baa77fffad9eb2d586565`
- WoL: MAC `70:85:C2:51:8F:17` / `selpix.duckdns.org:56700`
- 서버에서 WoL: `wakeonlan -i selpix.duckdns.org -p 56700 70:85:C2:51:8F:17`

### 서버에서 원격 제어 명령어
```bash

# 페이지 열기
```

### 주의사항
- **Browser Relay 확장 불필요** — `--browser-profile openclaw` (CDP 직접 연결)로 완전 대체
- `ws://` 비보안 차단됨 → Tailscale Serve(`wss://`) 필수
- Tailscale Serve 재시작은 startup.ps1이 자동 처리

### 서버에서 원격 제어 명령어 (CDP 프로필)
```bash
ALIAS="--browser-profile openclaw --url wss://desktop-ir43sud.tail39cdea.ts.net --token fcc0dfdd43df45229bfe4d7f704baa77fffad9eb2d586565"

# 탭 목록
openclaw browser tabs $ALIAS

# 페이지 열기
openclaw browser open "https://www.coupang.com" $ALIAS

# 포커스 + 스냅샷
openclaw browser focus <tab-id> $ALIAS
openclaw browser snapshot $ALIAS
```

### headless 대비 장점

| 비교 | Puppeteer (headless) | Browser Relay |
|------|---------------------|---------------|
| navigator.webdriver | 있음 (탐지됨) | **없음** |
| 브라우저 지문 | 가짜 | **진짜** |
| 쿠키/로그인 | 매번 새 세션 | **기존 유지** |
| 쿠팡 WAF | 차단됨 | **통과 가능성 높음** |
| CAPTCHA | 별도 처리 | 이미 풀린 상태 |

### 실사용 패턴

1. **가격 모니터링**: 쿠팡 로그인 탭 → 경쟁 상품 순회 → 가격 추출 → Telegram 알림
2. **셀러센터 데이터**: 판매 현황 대시보드 → 매출/주문/전환율 추출
3. **상품 리서치**: 카테고리 베스트셀러 → 스크롤 → 상품 데이터 추출
4. **멀티스텝**: 주문 확인 → 배송 정보 → 택배사 운송장 입력

### 결제/구매 자동화
- 장바구니, 배송지, 쿠폰 → **자동 가능**
- 최종 결제 → **사람이 확인** (한국 결제 ISP/OTP 팝업 때문)

### 제한사항
- 속도 제한(rate limiting) 준수 필수
- CAPTCHA 의도적으로 우회 안 함
- CDP 디버거 감지하는 고급 WAF 존재 (DataDome 등)
- 기계적 패턴이면 여전히 탐지 가능
