# 3대 장비 활용 계획

## 장비 역할

| 장비 | 위치 | 역할 | 가동 |
|------|------|------|------|
| Linux 서버 | 사무실 | OpenClaw 프로덕션 (24시간 자동화) | Always on |
| MacBook | 이동 | 코드 개발, SSH 원격 관리 | 업무시간 |
| Windows PC | 집 | GUI 시각적 작업, 데이터 분석 | 필요할 때만 |

## OS 결정

- **집 PC**: Windows 유지 + WSL2 (초기화 완료 후 세팅)
  - 윈도우 앱 병행 가능, WSL2로 Docker+Linux 환경
  - 대안: Pop!_OS 24.04 (완전 Linux 원하면)

## 네트워크: Tailscale

```
MacBook ──┐
           ├── Tailscale (무료, WireGuard 기반) ── 어디서든 SSH 접속
서버    ──┤
           └── 집 PC
```
- 무료 (100대, 3유저), 설치 5분, NAT 관통
- MagicDNS로 `ssh dev@office-server` 가능

## 도구 선택 요약

### 시각적 워크플로우
- **n8n** (추천) > Node-RED > Airflow
- Docker 한줄 셀프호스팅, 1100+ 커넥터, AI Agent 노드

### 데이터 분석
- **Grafana**: 실시간 모니터링 + 알림
- **Streamlit**: Python 데이터 앱
- **Jupyter Lab**: 탐색적 분석

### 브라우저 자동화
- **Playwright** (추천) > Puppeteer > Selenium
- Python 바인딩, 멀티 브라우저, 최고 속도

### 내부 대시보드
- **ToolJet/Appsmith** (오픈소스) > Retool (상용)
- AI 자연어 앱 생성, Docker 셀프호스팅

### VPN
- **Tailscale** (추천) > ZeroTier > WireGuard 수동

### 파일 동기화
- **Git**: 코드
- **Syncthing**: vault, 메모, 설정 파일
- **rsync**: 대용량 일괄 전송

### 모니터링
- **Healthchecks.io** (클라우드): 크론잡 감시 (무료 20개)
- **Uptime Kuma** (셀프호스팅): 서비스 감시
- **Telegram Bot**: 알림 채널

### .env 관리
- **SOPS + age**: 암호화 후 Git 커밋 가능, 기기별 키
