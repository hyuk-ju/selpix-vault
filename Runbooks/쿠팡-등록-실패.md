# Runbook: 쿠팡 등록 실패

## 증상 (Symptoms)
- 텔레그램 알림: "연속 에러: 최근 5건 중 3건 실패"
- register_queue.json에 `status: "error"` 항목 증가
- 30분 크론(cron_register_product.js) 실행 시 등록 0건

## 에러 유형별 원인

| 에러 | 원인 | 빈도 |
|------|------|------|
| INVALID_IMAGE | 이미지 URL에 `noimage`, `img_notExist` 등 포함 | 높음 |
| INVALID_ATTRIBUTE | 필수 속성 누락 (카테고리별 필수값 불일치) | 중간 |
| CATEGORY_ERROR | predictCategory API 실패 또는 카테고리 매핑 오류 | 낮음 |
| DUPLICATE_PRODUCT | 이미 쿠팡에 등록된 상품 | 낮음 |
| NETWORK_ERROR | 쿠팡 API ETIMEDOUT / fetch failed | 간헐적 |

## 재현 절차 (Steps to Reproduce)
1. 큐 상태 확인:
   ```bash
   cd /home/dev/openclaw/config/workspace/tmp/selpix-saas
   jq '[.[].status] | group_by(.) | map({(.[0]): length}) | add' data/register_queue.json
   ```
2. 에러 항목 확인:
   ```bash
   jq '[.[] | select(.status=="error")] | length' data/register_queue.json
   jq '[.[] | select(.status=="error")] | .[0:3] | .[] | {title: .productName, error, retryCount}' data/register_queue.json
   ```
3. 최근 로그 확인:
   ```bash
   ls -lt /home/dev/openclaw/data/logs/*cron_register* | head -3
   tail -50 /home/dev/openclaw/data/logs/$(ls -t /home/dev/openclaw/data/logs/*cron_register* | head -1)
   ```

## 해결 절차 (Resolution)

### 자동 복구 (pipeline_health_check.js가 처리)
- retryCount < 3인 에러 → 자동으로 pending 리셋
- 24h 이상 SEO 미완료 → seoTimedOut 강제 설정

### 수동 복구
1. **dry-run으로 리셋 대상 확인:**
   ```bash
   cd /home/dev/openclaw/config/workspace/tmp/selpix-saas
   node scripts/reset_errors.js --dry-run
   ```
2. **리셋 실행:**
   ```bash
   node scripts/reset_errors.js
   ```
3. **특정 에러만 정리 (skip_invalid 제외):**
   ```bash
   jq '[.[] | if .status == "error" and .retryCount < 3 then .status = "pending" else . end]' data/register_queue.json > /tmp/q.json && mv /tmp/q.json data/register_queue.json
   ```

### INVALID_IMAGE 반복 시
- `lib/image_utils.js`의 `INVALID_IMAGE_PATTERNS` 배열에 새 패턴 추가
- 소싱 단계(pipeline_sourcing.js)에서 이미지 URL 사전 검증 강화
