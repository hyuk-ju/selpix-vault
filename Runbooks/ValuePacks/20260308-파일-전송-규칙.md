# 파일 전송 규칙

summary: 사용자가 파일 전송을 요청하면 텍스트 대체나 되묻기보다 파일 존재 확인 후 sendDocument 경로로 즉시 처리한다.
decision: "파일 보내줘"류 요청은 설명보다 전송 실행이 우선이며, 실패 시 재시도/대안 전송 규칙을 따른다.
evidence_paths:
  - PROTOCOLS.md
  - scripts/lib/telegram.js
  - SYSTEM_STATE.md
exceptions:
  - 파일이 실제로 없거나 접근 불가면 없는 상태를 명시하고 대체 파일/생성 여부를 안내한다.
  - 채널 제한이나 파일 크기 이슈가 있으면 압축/분할/요약본 같은 대안을 제시한다.
action_rule:
  - 파일 존재를 먼저 확인한다.
  - 존재하면 sendDocument 규칙에 따라 즉시 전송한다.
  - 텍스트로 내용 붙여넣기, 불가 답변, 불필요한 되묻기는 금지한다.
  - 실패 시 오류와 대체 전송 경로를 짧게 정리한다.

## evidence
- PROTOCOLS.md §4는 파일 전송을 즉시 실행해야 하는 single source of truth로 명시한다.
- SYSTEM_STATE.md는 scripts/lib/telegram.js의 sendDocument 지원을 공유 참조로 둔다.
- 보고서 요청 시 HTML은 텔레그램 파일 전송으로 처리한다는 운영 선호 흔적이 남아 있다.

## notes
- 동일 채팅에서는 일반 답장과 파일 전송 경로를 혼동하지 않도록 주의한다.
- 파일 전송은 텍스트 응답 대체가 아니라 별도 행동으로 본다.
