# 에이전트 위임·결과전달 규칙

summary: 위임은 선언으로 끝내지 않고, 결과를 반드시 사용자에게 다시 전달해야 한다.
decision: 메인은 직접 실무보다 라우팅과 결과 전달에 집중하며, 위임 후 결과 회수·전달까지 완료해야 한다.
evidence_paths:
  - SOUL.md
  - AGENTS.md
  - MEMORY.md
exceptions:
  - 직접 실행 테이블에 있는 작업은 스크립트로 바로 처리한다.
  - 사용자가 단순 정보 설명만 원하는 경우 위임 없이 대화로 처리할 수 있다.
action_rule:
  - 리서치/코드/기획/감사 요청은 라우팅 테이블에 따라 적절한 에이전트로 보낸다.
  - 위임 후에는 결과 도착 시 사용자용으로 재정리해 반드시 전달한다.
  - '완료되면 전달할게'로 끝내고 누락하지 않는다.

## evidence
- SOUL.md 9.2.1은 위임 선언만으로 응답 완료를 금지하고, 결과가 돌아오면 반드시 전달하라고 명시한다.
- AGENTS.md는 메인이 직접 실무보다 오케스트레이션과 승인/소통 역할을 맡도록 규정한다.
- MEMORY.md에도 메인 세션에서 브라우저 스크래핑/리서치를 직접 수행하지 말고 전문 에이전트에 위임하는 운영 규칙이 정리되어 있다.

## notes
- 이 규칙은 멀티에이전트 품질의 핵심이므로 답변 완주율 KPI와 함께 본다.
- 위임 정확도와 결과 전달 누락률을 별도 지표로 추적하면 좋다.
