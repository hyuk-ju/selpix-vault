# Runbook: 파이프라인 정지

## 증상 (Symptoms)
- 텔레그램 알림: "[CRITICAL] 24h 등록 0건" 또는 "[CRITICAL] 파이프라인 정지: 연속 3일 신규 소싱 0건"
- register_queue.json에 새 pending 항목 없음
- 큐 정체: pending 10개 이상 + 24h 등록 0건

## 재현 절차 (Steps to Reproduce)
1. 큐 현황:
   ```bash
   cd /home/dev/openclaw/config/workspace/tmp/selpix-saas
   jq '[.[].status] | group_by(.) | map({(.[0]): length}) | add' data/register_queue.json
   ```
2. 최근 등록 확인:
   ```bash
   jq '[.[] | select(.status=="registered" or .status=="approved")] | sort_by(.registeredAt) | .[-3:] | .[] | {title: .productName, registeredAt}' data/register_queue.json
   ```
3. 소싱 로그 확인:
   ```bash
   ls -lt /home/dev/openclaw/data/logs/*pipeline_sourcing* | head -3
   ```
4. 크론잡 상태:
   ```bash
   crontab -l | grep -E "register|sourcing"
   ```

## 해결 절차 (Resolution)

### 소싱 정지 (신규 상품 0건)
1. 도매꾹 API 키 확인: `grep DOMEGGOOK /home/dev/openclaw/.env`
2. 수동 소싱 테스트:
   ```bash
   cd /home/dev/openclaw/config/workspace/tmp/selpix-saas
   node scripts/pipeline_sourcing.js 2>&1 | tail -20
   ```
3. 도매꾹 API 응답 확인 (HTTP 에러 코드)
4. 블랙리스트 과다 → `BLOCKED_KEYWORDS` 배열 점검

### 등록 정지 (pending → registered 0건)
1. SEO 최적화 대기 확인:
   ```bash
   jq '[.[] | select(.status=="pending" and .optimized!=true)] | length' data/register_queue.json
   ```
2. SEO 타임아웃 강제 (24h 이상 대기 시):
   ```bash
   node /home/dev/openclaw/config/workspace/scripts/pipeline_health_check.js
   ```
   → 자동으로 `seoTimedOut: true` 설정됨
3. 에러 리셋:
   ```bash
   node scripts/reset_errors.js --dry-run
   node scripts/reset_errors.js
   ```

### 큐 정체 (pending 과다)
1. pending 중 가장 오래된 항목 확인:
   ```bash
   jq '[.[] | select(.status=="pending")] | sort_by(.addedAt) | .[0:3] | .[] | {title: .productName, addedAt, optimized}' data/register_queue.json
   ```
2. 72h 이상 체류 항목 5개+ → 큐 노화 문제
3. 수동 등록 테스트로 API 동작 확인
