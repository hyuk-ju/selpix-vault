# ADR-020: AI 트렌드 초고속 학습→즉시 실행 오케스트레이터

## 맥락 (Context)
문제: AI 트렌드 변화가 빨라 정보 수집과 실행 사이에 지연이 큼. 제안: 트렌드 수집(유튜브/X/뉴스)→요약/검증→우선순위 점수화→즉시 실행 템플릿(콘텐츠, 자동화, SaaS 실험)까지 연결하는 오케스트레이터를 구축. 목표는 학습-실행 간 리드타임을 24시간 이내로 줄이고, 주간 실험 수를 늘리는 것.

## 결정 (Decision)
**⏸️ 보류**
- 시장: 보류 — 수요 적합도는 높고 시장 타이밍도 유효하나, 경쟁 솔루션 밀집으로 초기 시장 진입 비용이 높고 데이터 신뢰도·요약 정확도·자동 실행 실패율에 대한 실증이 선행되어야 합니다. 특히 트렌드 수집-요약-실행의 체감 가치를 ‘시간 절약량’이 아닌 실제 매출 연결 지표로 입증하지 못하면 차별화 지속이 어렵습니다. 따라서 2주 내 실험(KPI 고정, 실패율 상한/정성 피드백)을 통한 검증 후 확장으로 가는 단계적 진입이 권장됩니다.
- 기술: 보류 — 문제-해결 적합성이 높고 자동화 효과가 크지만, 초기에는 데이터 신뢰도와 실행 품질 통제가 핵심 병목이다. 따라서 소규모 소스와 휴먼 승인 기반 파일럿으로 리드타임 24시간 목표를 검증한 뒤 자동 실행 범위를 단계적으로 확장하는 접근이 가장 현실적이다.
- 비즈니스: 보류 — 트렌드 수집·큐레이션 자체는 시장 경쟁이 치열하고 API 정책 변경/노이즈 데이터로 인한 품질 편차 위험이 큼. 즉시 실행 오케스트레이션까지 완결하려면 데이터 신뢰도·통합 커넥터·법규/브랜드 리스크 대응이 추가되어야 하며, 현 상태의 범위에서 차별화 포인트가 명확하지 않다. 특정 수직군(예: 중견 B2B 마케팅 조직, 게임·핀테크 등 규제 약한 산업)으로 좁혀 MVP 검증 후 재평가가 필요하다.
- Critic: 보류 — 비즈니스 기회 자체는 유의미하나, 핵심 전제(외부 데이터 계층 안정성·요약 신뢰도·자동 실행 안전성)가 미검증 상태이고, 현재는 trend/tech 정식 분석 결과도 반영되지 않은 채로 진행되는 것으로 보인다. 우선 데이터 신뢰도와 오탐 통제 체계를 수치로 입증한 뒤 단계 축소 운영으로 재평가해야 한다.
