# ADR-001: AI 블로그 자동화 SaaS

## 맥락 (Context)
키워드 입력하면 SEO 최적화된 블로그 포스트를 자동 생성하는 SaaS. 월 $19 구독.

## 결정 (Decision)
**✅ 추천 (주의 필요)**
- 시장: 보류 — 레드오션이나 한국어 특화 니치 가능
- 기술: 추천 — 기술적 진입장벽 낮음
- 비즈니스: 추천 — 낮은 초기 비용, 반복 수익 모델
- Critic: 보류 — Google 패널티 리스크 + 시장 규모 우려

## 검토한 대안 (Options)
대안1: 블로그 대신 상품 설명문 자동화 (쿠팡셀러 타겟) / 대안2: 기존 콘텐츠 리라이팅 + SEO 진단 도구

## 트레이드오프 (Consequences)
- 실행 시: 경쟁사 5개 기능 비교표 작성 → MVP 프로토타입 + GPT 프롬프트 설계 → 랜딩페이지 + 베타 신청 폼
- 미실행 시: 기회 비용 발생

## 리스크 및 탐지 신호
| 리스크 | 내용 | 탐지 신호 |
|--------|------|-----------|
| 치명적 결함 | Google이 AI 콘텐츠 패널티 강화하면 핵심 가치 소멸 | 초기 검증 실패 |
| 시장 리스크 | 한국어 시장 규모가 글로벌 대비 1/50 | 수요 지표 하락 |
| 실행 리스크 | SEO 품질이 GPT 기본 출력으로는 부족 | MVP 일정 초과 |
