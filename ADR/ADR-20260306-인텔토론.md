# ADR-20260306 인텔 토론

## Decision
- 최종 판정: approved 0건 / deferred 5건 / rejected 17건
- 판정 규칙: 3/3 approve => approved, 2/3 approve + low => approved, 2/3 approve + medium/high => deferred, 그 외 rejected

## Assumptions
- 입력 파일(intel_proposals.json, intel_eval_biz.json, intel_eval_ops.json)은 동일한 id/title 기반으로 매칭 가능하다고 가정
- risk는 low/medium/high 중 하나이며 최종 risk는 3개 평가의 최대 위험도를 사용
- update_fee_table은 자동 적용 금지 원칙 유지
