# ADR-20260403-인텔토론

## Decision
- 승인 1건: `요가매트 검색어 상승률(네이버) 급등 감시 워치카드 추가`
- 기각 2건:
  - `GitHub 비공개 레포 학습 오차단(opt-out) 임박(4/24) 정책 변경 모니터링`
  - `오픈소스 AI 런타임·프레임워크 동시 릴리스 증가 모니터링`
- 종합 판정은 `data/intel_proposals.json`, `data/intel_eval_biz.json`, `data/intel_eval_ops.json` 3개 입력을 기준으로 규칙 적용:
  - 3/3 approve → approved
  - 2/3 approve + risk low → approved
  - 2/3 approve + risk medium/high → deferred
  - 그 외 → rejected
- 최근 3일 동일/유사 제안 강제 reject 여부는 `memory_search`와 `vault/Memory/변경로그.md` 기준 확인했으나 본 건들과 직접 일치하는 최근 3일 ADR 증거는 확인되지 않았다. 다만 오픈소스 릴리스 모니터링 제안은 이미 briefing 수집 범위에 포함되어 운영 중복으로 reject 처리했다.

## Assumptions
- `data/intel_proposals.json`의 verdict/reason/risk는 trend 관점 1표로 간주했다.
- `data/intel_eval_biz.json`은 biz 관점 최종 입력으로 사용했다.
- `data/intel_eval_ops.json`은 기술/운영 안정 관점 최종 입력으로 새로 작성했다.
- 제안 원문에 action/value가 없어 자동 적용 스크립트에는 승인 건이 있어도 구체 액션 없이 전달된다.
- 증거 없는 정책 해석이나 외부 사실 추정은 배제했다.

## Options
1. 요가매트 상승 키워드를 신규 워치카드로 승인
   - 장점: 신규 수요 신호 반영, 운영 변경 없음, 리스크 낮음
   - 단점: 아직 직접 매출 액션으로 연결되진 않음
2. GitHub private repo 학습 opt-out 정책 이슈를 즉시 승인
   - 장점: 보안 이슈 선제 감시
   - 단점: 정책 원문/영향 범위 미검증 상태
3. 오픈소스 AI 릴리스 급증 모니터링을 추가 승인
   - 장점: 스택 변동성 감시 강화
   - 단점: 기존 briefing/github_releases와 중복, 운영 잡음 증가

## Risks
- 승인 건은 구체 action/value가 없어 `apply_intel.js`에서 실제 변경 없이 스킵될 수 있다.
- GitHub 정책 이슈는 확인 전 확대 해석 시 불필요한 보안 대응을 유발할 수 있다.
- 오픈소스 릴리스 감시는 이미 수집 중인 신호와 중복되면 운영 피로만 늘릴 수 있다.
