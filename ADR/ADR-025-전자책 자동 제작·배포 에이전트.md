# ADR-025: 전자책 자동 제작·배포 에이전트

## 맥락
Source: 메이커 에반: '누워서 딸깍 한번에 전자책 완성' 영상, Nick Saraev의 Build & Sell/CLAUDE CODE 교육 흐름.
구성: 자료조사-원고-디자인-검수-발행까지 API 기반 자동 루틴을 한 번에 설정, OpenClaw 워크플로우 또는 독립 UI로 추상화.
수익화: 생성형 에이전트 구독 + 완성본 상위 템플릿 판매(월 $19~).

## 결정
**⏸️ 보류**
- 시장: 보류 — 콘텐츠 제작 자동화 수요는 존재하나, 콘텐츠 제작자용으로는 이미 유사 AI 글쓰기/템플릿/배포 툴이 포화되어 ‘원클릭’만으로 즉시 차별화되기 어렵다. 특히 전자책 품질·브랜딩 일관성·지원 부하를 확보하지 못하면 환불과 이탈 리스크가 커진다.
- 기술: 보류 — 핵심 기능은 기존 LLM·문서 렌더링·결제 API 조합으로 구현 가능하지만, ‘자동 제작+배포’ 전체를 원클릭으로 묶으면 품질 편차와 예외 처리 비용이 초기에 크게 증가한다. MVP는 생성·검수·배포 범위를 좁혀 단계 검증이 필요하다.
- 비즈니스: 보류 — 초기 고객 수요는 있으나 범용 AI 저작/디자인 툴 대비 차별화가 약하면 CAC 대비 회수 기간이 길어질 가능성이 크다. ICP를 좁힌 파일럿 매출 검증 전까지 보수적 접근이 필요하다.
- 반대 검증: 보류 — 경쟁이 이미 성숙한 시장에서 '원클릭 전자책 자동 제작·배포'는 차별화가 약하고, 품질 편차·검수 실패를 막기 위한 운영 비용이 초기 수익성보다 앞서 발생할 위험이 높다. 유료 전환율, 반품률, 배포/저작권 오류율이 낮아지지 않으면 파일럿 단계에서 비용이 이익을 잠식할 가능성이 크다.

## 트레이드오프
- 실행 시: 타깃 세그먼트 확정 + KPI 정의 → 핵심 세그먼트 파일럿 운영 → KPI 기반 패키지/가격 조정
- 미실행 시: 기회 비용 발생

## 리스크 및 탐지 신호
| 리스크 | 내용 | 탐지 신호 |
|--------|------|-----------|
| 치명적 결함 | 범용 AI 글쓰기/디자인/배포 툴 대비 가치 제안이 약해 가격 압박 및 기능 모방이 쉬움,원클릭 자동화에서 품질/브랜딩 일관성 보장 실패가 누적되면 환불·이탈로 CS 비용이 급증,LLM·문서렌더링·결제·채널 연동 의존도가 높아 장애·요금 변동 시 서비스 신뢰도가 즉시 하락 | 초기 검증 실패 |
