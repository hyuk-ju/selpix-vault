# ADR-20260405-인텔토론

## Decision
- 승인 1건: `요가매트 동의어(요가매트가방/필라테스매트) 탐지 강화`
- 보류 1건: `GitHub 비공개 저장소 학습 이슈 선행 감시 키워드 등록`
- 기각 2건:
  - `캠핑 초보 장비 수요 반영을 위한 YouTube 쿼리 추가`
  - `오픈소스 AI 런타임·프레임워크 동시 릴리스 증가 모니터링`
- 판정 규칙 적용:
  - 3/3 approve → approved
  - 2/3 approve + risk low → approved
  - 2/3 approve + risk medium/high → deferred
  - 그 외 → rejected
- 다만 이번 입력은 `data/intel_briefing.json` 생성 시각이 2026-03-28로 확인됐고, 평가 파일 간 제목 불일치가 있어 완전한 동일 사이클 산출물로 검증되지는 않았다.

## Assumptions
- 최근 3일 ADR 확인 대상 중 `ADR-20260404-인텔토론.md`, `ADR-20260402-인텔토론.md`는 파일이 없었고 `ADR-20260403-인텔토론.md`만 존재했다.
- 요가매트 관련 biz/ops 평가는 제목이 `워치카드 추가`로 다르지만 동일한 상승 신호 기반 모니터링 보강으로 매핑 가능하다고 판단했다.
- GitHub private repo 이슈는 trend/biz/ops 모두 같은 정책 모니터링 주제로 해석 가능했다.
- 캠핑 YouTube 쿼리 추가는 biz/ops 대응 평가가 없어 억지 매핑을 하지 않았다.
- `update_fee_table` 제안은 없었고 자동 적용 대상에서도 제외했다.
- `build_intel_briefing.js`, `apply_intel.js`, `digest_accumulator.js` 실행은 권한 승인 요구로 이번 턴에서 실제 수행하지 못했다.

## Options
1. 요가매트 동의어 탐지 강화 승인
   - 장점: 상승 수요와 공급망 태그 분산을 함께 포착, low risk
   - 단점: 실제 매출 기여는 후속 모니터링이 필요
2. GitHub 정책 이슈 감시 키워드 승인
   - 장점: 코드 자산/정책 변화 조기 탐지
   - 단점: 정책 본문 검증 전에는 대응 범위가 모호
3. 캠핑 초보 장비 YouTube 쿼리 추가 승인
   - 장점: 콘텐츠 수집 범위 확대
   - 단점: biz/ops 동의 증거 부재
4. 오픈소스 런타임 릴리스 감시 추가 승인
   - 장점: 기술 변화 추적 강화
   - 단점: 기존 github_releases 수집과 중복 가능성이 높음

## Risks
- `data/intel_briefing.json`이 최신 생성물이 아니어서 이번 사이클 입력 신선도가 낮다.
- `data/intel_proposals.json`과 `data/intel_eval_biz.json`/`data/intel_eval_ops.json`의 제목 세트가 다르다. 즉, 동일 토론 라운드 산출물인지 확정할 수 없다.
- 권한 승인 부재로 `apply_intel.js`와 `digest_accumulator.js`를 실행하지 못해 자동 반영/다이제스트 축적이 미완료 상태다.
- 중복 방지 검증은 존재 파일 기준으로만 수행했으며, 누락된 ADR 파일이 있다면 판단이 달라질 수 있다.

## Next Actions
- `build_intel_briefing.js`를 실제 재실행해 최신 `data/intel_briefing.json`을 생성할 것.
- trend/biz/ops 세 파일을 같은 사이클 기준으로 재생성해 제목 정합성을 맞출 것.
- 승인 후 필요 시 `apply_intel.js`를 실행하되 `update_fee_table`은 계속 자동 적용 금지 유지.
- `digest_accumulator.js --job "intel-discussion-loop" ...`로 결과를 다이제스트에 적재할 것.
