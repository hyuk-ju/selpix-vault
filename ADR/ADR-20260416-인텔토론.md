# ADR-20260416-인텔토론

## Decision
- 적용: **0건**
- 보류: **0건**
- 거부: **0건**
- 추가 결정: 제안 파일이 비어 있어 금일 자동 적용은 수행하지 않는다.

## Assumptions
- SYSTEM_STATE.md 기준 운영 안정 우선 원칙을 유지했다.
- 최근 3일 ADR 중 확인 가능한 파일은 2026-04-14 문서였고, 동일/유사 제안 중복은 발견되지 않았다.
- `scripts/build_intel_briefing.js` 실행은 EACCES로 실패했고, 기존 `data/intel_briefing.json`을 근거 데이터로 사용했다.
- `data/intel_eval_biz.json`, `data/intel_eval_ops.json`의 평가는 proposal id와 일치하지 않아 합의 계산에서 제외했다.

## Options
1. 신규 제안 없음
   - trend-scout: 빈 배열
   - biz-writer: proposal id 불일치 평가 1건
   - ops-dev: proposal id 불일치 평가 1건
   - 결론: 합의 계산 대상 없음

## Risks
- 브리핑 스크립트가 호스트 절대경로로 저장을 시도해 샌드박스에서 직접 생성에 실패했다.
- 제안 파일과 평가 파일의 id 정합성이 깨지면 자동 합의 로직이 무효화된다.
- 데이터 정합성 문제가 지속되면 approved 비율이 왜곡될 수 있다.

## Next Actions
- 승인 건이 없어 `scripts/apply_intel.js`는 실행하지 않는다.
- 다음 루프에서 `build_intel_briefing.js`의 저장 경로 호환성과 proposal/eval id 정합성을 우선 점검한다.
- `update_fee_table` 자동 적용 금지 원칙은 계속 유지한다.
