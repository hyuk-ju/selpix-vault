# ADR-20260305-인텔토론

## Decision
- 인텔 토론 결과: **approved 0건 / deferred 3건 / rejected 1건**
- 최종 상태:
  - 20260304-ip-01: deferred (risk: medium)
  - 20260304-ip-02: deferred (risk: medium)
  - 20260304-ip-03: deferred (risk: medium)
  - 20260304-ip-04: rejected (risk: medium)
- 승인 건이 없어 `apply_intel.js`는 실행하지 않음.

## Assumptions
- 판단 규칙은 작업 지시의 합의 규칙(3/3 승인, 2/3+low 승인, 2/3+medium/high 보류, 나머지 거부)을 그대로 적용했다.
- 리스크는 proposal/biz/ops 평가의 최대 리스크를 최종 리스크로 간주했다.
- `update_fee_table`은 자동 적용 금지 규칙을 준수했다.

## Options
1. **즉시 적용(미채택)**: 승인 건이 없으므로 불가.
2. **보류 유지(채택)**: medium risk 3건은 추가 데이터 확보 후 재평가.
3. **완전 폐기(부분 채택)**: 합의 부족 1건은 rejected로 폐기.

## Risks
- medium risk 항목을 성급히 적용하면 노이즈 키워드 유입으로 수집 품질 저하 가능.
- 보류 장기화 시 트렌드 반영 지연 위험 존재.
- 평가 기준 불일치(에이전트 간 관점 차이)로 deferred 누적 가능.

## Next Actions
- deferred 3건은 24시간 내 신규 신호(재등장 빈도/전환 지표) 확인 후 재토론.
- rejected 1건은 동일 패턴 재발 시 대체 키워드로 재제안.
- 다음 루프에서 risk 근거를 정량 지표(빈도/성과)와 함께 제출하도록 평가 프롬프트 강화.
