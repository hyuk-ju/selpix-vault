# ADR-20260417-인텔토론

## Decision
- 적용: **2건**
- 보류: **1건**
- 거부: **0건**
- 텀블러·주방용품 동시 상승 기반 생활소품 소싱 후보 재정비: deferred (approve 2/3, risk high)
- Codex 기능 강화와 OpenClaw 포지셔닝 재점검: approved (approve 3/3, risk low)
- 클라우드 API 키·크레덴셜 손상 대응 규칙 강화 제안: approved (approve 3/3, risk high)

## Assumptions
- SYSTEM_STATE.md 기준 운영 안정 우선 원칙을 유지했다.
- 최근 3일 ADR 확인 결과 2026-04-16은 제안 없음, 2026-04-14는 충전기 키워드 성장 감지 제안이 deferred(high risk)였다.
- 2026-04-15 ADR 파일은 확인되지 않아 중복 검토는 확인 가능한 기록 기준으로 수행했다.
- build_intel_briefing.js 원본 실행은 EACCES로 실패해 동일 로직을 워크스페이스 경로로 재실행해 briefing을 생성했다.
- biz-writer, ops-dev 평가 파일이 빈 배열이어서 누락 평가는 approve로 간주하지 않았다.

## Options
1. 텀블러·주방용품 동시 상승 기반 생활소품 소싱 후보 재정비
   - 결정: deferred
   - 근거: trend-scout: approve (운영 여력이 충분하고 카테고리 다양화 여지가 커 즉시 탐색 성과로 연결할 수 있다.) / biz-writer: approve (수요 신호와 운영 여력이 모두 확인돼 생활소품 카테고리에서 후보 갱신 효과가 바로 매출 연결될 가능성이 높다.) / ops-dev: reject (최근 3일 내 키워드 상승 기반 소싱 확장 제안이 이미 high risk로 보류됐다. 생활소품으로 카테고리는 달라도 운영 패턴이 유사해 재등장 제안으로 보고 보수적으로 기각한다.)
2. Codex 기능 강화와 OpenClaw 포지셔닝 재점검
   - 결정: approved
   - 근거: trend-scout: approve (수요가 높은 엔드유저 생산성 시나리오에서 격차를 줄여 전환율/채택률을 높일 기회가 있다.) / biz-writer: approve (경쟁 기능 갭을 선제 정리해 생산성/개발자 지향 고객군에서 채택 장벽을 낮추고 전환 기회를 확보할 수 있다.) / ops-dev: approve (문서화와 우선순위 재정의 중심이라 시스템 변경 없이 경쟁 리스크를 정리할 수 있다. 자동 적용 없이 분석 산출물만 만들면 되어 운영 충돌이 작다.)
3. 클라우드 API 키·크레덴셜 손상 대응 규칙 강화 제안
   - 결정: approved
   - 근거: trend-scout: approve (비용 급증과 서비스 중단 가능성이 높아 운영 위험을 선제적으로 낮출 필요가 크다.) / biz-writer: approve (과금 급증 및 서비스 중단 리스크가 명시돼 있어, 대응 SOP 정비는 손실 축소와 운영 안정성 강화에 직접적 효과가 크다.) / ops-dev: approve (비용 폭주와 세션 손상 사례가 이미 확인돼 운영 SOP 강화 필요성이 높다. 자동 적용이 아니라 규칙과 대응 절차 정비라 통제 가능 범위 안이다.)

## Risks
- 원본 브리핑 스크립트가 호스트 절대경로를 사용해 샌드박스에서 직접 저장되지 않았다.
- biz/ops 평가 누락이 지속되면 approved 비율이 왜곡될 수 있다.
- 동일/유사 제안 중복 방지는 확인 가능한 최근 ADR 기준으로만 검증됐다.
- update_fee_table 자동 적용 금지 원칙은 계속 유지한다.
