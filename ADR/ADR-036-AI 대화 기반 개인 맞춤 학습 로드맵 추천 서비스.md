# ADR-036: AI 대화 기반 개인 맞춤 학습 로드맵 추천 서비스

## 맥락
사용자가 ChatGPT/Claude 등과 나눈 대화 내용을 업로드하거나 연동하면, AI가 목표(시험/직무/취미), 현재 수준, 가용 시간, 선호 학습 방식, 제약 조건을 추출해 1) 주차별 학습 계획 2) 우선순위 개념 맵 3) 추천 교재/도서/보조 자료 4) 복습·진도 체크 루틴을 자동 생성한다. 단순 요약이 아니라 학습 설계(진단→계획→실행→피드백)를 제공하는 것이 핵심이다. 초기에는 특정 과목군(예: 개발/영어)에 한정해 추천 정확도와 실행 전환율을 검증한다.

## 결정
**⚠️ 조건부 추천 (리스크 주의)**
- 시장: 추천 — 명확한 문제(무엇을 어떻게 배울지 결정 어려움)를 해결하며, 초기에는 특정 직무군(예: 데이터 분석 입문)으로 좁혀 MVP 검증이 유리함
- 기술: 추천 — 핵심 가치(개인화 학습 계획 자동화)가 명확하고, 기술 난이도 대비 사용자 체감 효용이 크다. Node.js/Docker로 8주 내 MVP 검증이 가능하며, 위험요소는 입력 표준화·사용자 확인 루프·보안 설계로 관리 가능하다.
- 비즈니스: 추천 — 문제-시장 적합성이 높고(학습 계획 수립/지속 어려움), AI 대화형 UX로 초기 진입장벽을 낮출 수 있어 상용화 가능성이 큼. 다만 경쟁이 빠르게 범용화되는 영역이므로 차별화는 '학습 성과 개선 데이터'와 '리텐션 루프(진도 추적→리플랜→동기부여)'에서 만들어야 함. 현재 가정상 LTV/CAC 1.7로 공격적 확장 전 채널 효율·유지율 개선이 선행되어야 하며, B2B2C 병행 전략이 손익 안정화에 유리함.
- 반대 검증: 반대 — 핵심 위험은 차별화 부재와 성과 인과 입증 실패다. 이 두 축이 해결되지 않으면 CAC 회수 이전에 해지율이 높아지고, 무료 대체재 대비 비용 정당화가 불가능하다. 현재 가정 하에서는 시장성과 실행 가능성 모두 high risk로, 즉시 투자/확장을 권고하기 어렵다.
