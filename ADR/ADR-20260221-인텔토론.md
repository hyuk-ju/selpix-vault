# ADR-20260221: 인텔 자동 적용 토론 결과

### 1. Decision (확정 결론)
- add_twitter_keyword: GPT-5.2 - (add_twitter_keyword(GPT-5.2)은 현재 watchlist(models/general)에 중복이 없고 즉시 적용 가능한 저위험 변경입니다.)
- add_twitter_keyword: GPT-5.3 - (add_twitter_keyword(GPT-5.3)도 중복 없이 적용 가능하며 트렌드 감지 분해능을 높입니다.)
- add_twitter_keyword: Gemini 3.1 Pro - (add_twitter_keyword(Gemini 3.1 Pro)는 현재 목록에 없고 구체 버전 추적 관점에서 기술 적용성이 높습니다.)
- add_twitter_keyword: Deep Think - (add_twitter_keyword(Deep Think)는 적용 가능하며 공식 계정 문구 포착에 유효합니다.)
- add_twitter_keyword: EVMbench - (add_twitter_keyword(EVMbench)는 현재 중복이 없고 기술적으로 바로 반영 가능합니다.)
- add_synonym: agentic - (add_synonym 제안값이 문자열('agentic')인데 apply_intel.js의 addSynonym 핸들러는 value.term/value.synonyms 객체를 요구하여 현재 스키마로는 적용 불가입니다.)
- add_trend_keyword: 텀블러 - (add_trend_keyword(텀블러)는 trend_aggregator.py TRACKED_KEYWORDS에 이미 존재해 중복 추가 대상입니다.)
- add_trend_keyword: 요가매트 - (add_trend_keyword(요가매트)도 TRACKED_KEYWORDS에 이미 포함되어 있어 신규 적용 이점이 없습니다.)
- add_youtube_query: 국산 주방용품 추천 - (add_youtube_query(국산 주방용품 추천)는 YOUTUBE_QUERIES에 미등록이며 문자열 추가 방식으로 즉시 적용 가능합니다.)

### 2. Assumptions (가정)
- [확실] 오늘 수집된 브리핑 데이터는 유효함
- [가정] 해당 키워드/액션이 타겟 시장과 관련성이 높을 것임

### 3. Options Considered (검토한 대안)
| 대안 | 요약 | 버린 이유 |
|------|------|-----------|
| add_twitter_keyword:GPT-5.2 | 브리핑의 트렌드 신호 48건 중 OpenAI의 공식 계정 글에서 GPT-5.2가 논문·deep research 롤아웃로 다수 언급됨. 버전급 신호가 누락되지 않도록 GPT-5 자체 키워드에 하위 버전 필터를 추가 필요. | 대안 대비 신호 강도/합의가 높아 채택 |
| add_twitter_keyword:GPT-5.3 | 브리핑에서 Codex 롤아웃 문구에 GPT-5.3-Codex-Spark가 등장하여 단기 성능 변화 신호 감지 강화 필요. | 대안 대비 신호 강도/합의가 높아 채택 |
| add_twitter_keyword:Gemini 3.1 Pro | GoogleDeepMind 계정 중심으로 Gemini 3.1 Pro 롤아웃, 가격/채널 공개가 반복됨. Gemini 3/2 계열 키워드로는 버전별 변화를 분리 추적하기 어려움. | 대안 대비 신호 강도/합의가 높아 채택 |
