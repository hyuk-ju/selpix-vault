# ADR-001: AI 코드리뷰 SaaS

## 맥락 (Context)
GPT 기반 PR 코드리뷰를 자동화하고 월 $29 구독 모델로 판매. 개인 개발자 타겟.

## 결정 (Decision)
**⏸️ 보류 (리스크 검토 필요)**
- 시장: 보류 — 경쟁 과열로 차별화 없이는 수익 어려움
- 기술: 추천 — 기술적으로 빠른 MVP 가능
- 비즈니스: 추천 — 구독 모델 수익성 확보 가능
- Critic: 반대 — 레드오션 + 플랫폼 종속 리스크가 치명적

## 검토한 대안 (Options)
대안1: 코드리뷰 대신 보안 취약점 스캔 특화 (SAST) / 대안2: 엔터프라이즈 전용 온프레미스 리뷰 봇

## 트레이드오프 (Consequences)
- 실행 시: 경쟁사 분석 + 차별화 포인트 정리 → GitHub App MVP + GPT 프롬프트 설계 → 베타 배포 + 개발자 커뮤니티 마케팅
- 미실행 시: 기회 비용 발생

## 리스크 및 탐지 신호
| 리스크 | 내용 | 탐지 신호 |
|--------|------|-----------|
| 치명적 결함 | GitHub Copilot이 네이티브 리뷰 기능 추가하면 즉사 | 초기 검증 실패 |
| 시장 리스크 | 개인 개발자 유료 전환율 극히 낮음 (1-2%) | 수요 지표 하락 |
| 실행 리스크 | GPT 할루시네이션으로 잘못된 리뷰 생성 시 신뢰 붕괴 | MVP 일정 초과 |
