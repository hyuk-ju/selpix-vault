# ADR-002: AI 블로그 자동화 SaaS

## 맥락 (Context)
키워드 입력하면 SEO 최적화된 블로그 포스트를 자동 생성하는 SaaS. 월 $19 구독.

## 결정 (Decision)
**🔥 강력 추천**
- 시장: 추천 — 명확한 타겟 + 경쟁 부재
- 기술: 추천 — 기존 인프라 재활용으로 빠른 개발
- 비즈니스: 추천 — 높은 반복 수익 + 낮은 이탈률 예상
- Critic: 추천 — 피벗 방향이 원래보다 확실히 낫고, 리스크 관리 가능

## 검토한 대안 (Options)
대안: 설명문+이미지+가격 통합 최적화 패키지로 확장

## 트레이드오프 (Consequences)
- 실행 시: 쿠팡 셀러 커뮤니티 수요 조사 → GPT 프롬프트 10개 카테고리 테스트 → MVP + 네이버 카페 홍보
- 미실행 시: 기회 비용 발생

## 리스크 및 탐지 신호
| 리스크 | 내용 | 탐지 신호 |
|--------|------|-----------|
| 치명적 결함 | 쿠팡이 자체 AI 설명 도구 출시 시 경쟁력 소멸 | 초기 검증 실패 |
| 시장 리스크 | 셀러 유료 전환 의지 불확실 | 수요 지표 하락 |
| 실행 리스크 | 카테고리별 품질 차이가 클 수 있음 | MVP 일정 초과 |
