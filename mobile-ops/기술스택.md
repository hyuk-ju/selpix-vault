# Mobile Ops - 기술 스택

> 모바일 지휘형 AI 운영실 템플릿 (ADR-033)

|----------|------|------|-----------|

## 선택 과정 (의사결정 근거)

### ORM: Drizzle > Prisma
- Prisma가 AI 레퍼런스는 더 많지만 Supabase(Postgres)와 직접 SQL 매핑되는 Drizzle이 더 자연스러움
- 서버리스(Vercel) 환경에서 번들 사이즈 유리
- SQL 기반이라 AI가 SQL 지식을 직접 전이 가능

### 작업 큐: Trigger.dev > BullMQ > Inngest
- BullMQ는 레퍼런스 최다지만 별도 Redis + 워커 프로세스 필요
- Inngest는 서버리스 호환이지만 셀프호스트 불가
- Trigger.dev는 서버리스 호환 + 셀프호스트 가능 + AI 에이전트 long-running 특화

### 봇: grammY > Telegraf
- npm 주간 다운로드 1.2M vs 160K (7.5배)
- TypeScript 네이티브 (Telegraf은 JS→TS 마이그레이션으로 타입 복잡)
- 최신 Bot API 지원 속도 빠름

## 아키텍처

```
[Telegram User] → webhook → [Next.js /api/bot] → grammY
                                    ↓
                            [Supabase DB] ←→ [Dashboard Pages]
                                    ↓               ↑
                            [Trigger.dev] → [Task Result] → [Supabase Realtime]
```

단일 Next.js 앱에 봇 웹훅 + 대시보드 + API 통합. 별도 서버 없음.
