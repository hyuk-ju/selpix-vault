## 쿠팡 API 핵심 규칙

- **NUMBER 속성**: 단위 접미사 필수 (`100` → `100g`)
- **groupNumber 중복**: 같은 groupNumber면 하나만 전송
- **가격 계산**: `perUnitCost = price + shipping/minOrder` (개당 원가!)
- **상품 수정**: GET → merge → PUT 전체 payload (부분 업데이트 불가)
- **임시저장 복구**: GET → PUT 재전송
- **판매 재개**: `PUT vendor-items/{id}/sales/resume`
- **판매중지 후 삭제**: `sales/stop` 먼저 → DELETE
