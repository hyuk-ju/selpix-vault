# n8n + 로컬 LLM 하이브리드 아키텍처 기획

> Codex Pro 토큰을 허드렛일에 낭비하지 않고, 고부가 AI 작업에 집중 투입하는 3티어 구조.

## 배경

### 현재 문제
- ChatGPT Pro $200/월 구독 중, **토큰 사용률 ~13%** (87% 미사용)
- openclaw-gateway 크론잡 32개 중 상당수가 **LLM 불필요한 bash 실행** (git push, 스크립트 실행)
- 이런 단순 작업에 Codex 토큰 소비 = 비효율

### Codex Pro 리소스 현황

| 리소스 | 5시간당 한도 | 현재 사용 |
|--------|-------------|-----------|
| 로컬 메시지 | 300~1,500 | ~13% |
| 클라우드 태스크 | 50~400 | 거의 미사용 |
| 주간 코드 리뷰 | 100~250 | 미사용 |

### 기존 인프라
- n8n 이미 설치 완료 (`http://100.106.56.16:5678`, Phase 3)
- Ollama v0.16.3 윈도우 PC 설치 완료 (GTX 1060 6GB)
- 서버(rod-bot) 24시간 가동 중

## Phase 1: n8n 이관 대상 (Tier 1)

### 즉시 이관 가능 (LLM 0%)

| 현재 크론잡 | 하는 일 | n8n 노드 |
|------------|---------|----------|
| vault-git-backup | `git add && commit && push` | Cron → Execute Command |
| config-git-backup | `git add && commit && push` | Cron → Execute Command |
| vault-auto-sync | git sync | Cron → Execute Command |
| cron-health-check | 스크립트 실행 + 알림 | Execute Command → IF → Telegram |
| PC 출근 WoL | ping → wakeonlan | Cron → Execute → IF → Telegram |
| PC 퇴근 shutdown | ping → ssh shutdown | Cron → Execute → IF(busy) → Telegram |

### 스크립트 실행 위주 (LLM 거의 불필요)

| 크론잡 | n8n 전환 |
|--------|----------|
| 도매꾹 품절 모니터링 | Execute Command → Telegram |
| seller-stats-daily | Execute Command → Telegram |
| coupang-price-monitor | Execute Command → Telegram |
| system-audit-periodic | Execute Command → IF(critical) → Telegram |

### 절감 효과
- **~10개 잡 x 하루 1~6회 = 하루 20~60 Codex 메시지 절약**
- 연간 ~$0 추가 비용 (Docker 자체 호스팅)

## Phase 2: Ollama 활용 (Tier 2)

### n8n → Ollama 연동
- n8n의 Ollama Chat Model 노드로 직접 연결
- `http://100.113.239.15:11434` (윈도우 PC Tailscale IP)
- 모델: `qwen2.5-coder:7b` (6GB VRAM에 적합)

### 이관 대상

| 작업 | 현재 (Codex) | Ollama로 |
|------|-------------|----------|
| 트윗 분류/필터링 | Codex가 텍스트 읽고 판단 | qwen2.5 간단 분류 |
| 일일 메트릭 요약 | Codex가 JSON → 문장 | Ollama 템플릿 채우기 |
| vault health 결과 요약 | Codex가 리포트 작성 | Ollama 포맷팅 |
| 단순 알림 메시지 생성 | Codex가 문장 작성 | Ollama 템플릿 |

### 제한사항
- GTX 1060 = 7B 모델이 한계, 복잡한 한국어 추론은 부족
- PC 꺼져 있으면 Tier 2 불가 → Tier 3 fallback 필요
- n8n 워크플로우에서 IF(PC online) → Ollama / ELSE → Codex API 분기

## Phase 3: Codex 집중 투입 (Tier 3)

### 기존 유지 (고부가 작업)
- intel-discussion-loop (멀티에이전트 토론)
- idea-lab-loop (아이디어 검증)
- coding-execution-loop (코드 생성)
- coupang-trend-research (심층 트렌드)
- daily-briefing (종합 브리핑)
- selpix-morning / selpix-evening (전략 리포트)

### 신규 추가 (절약된 토큰으로)

| 신규 작업 | 설명 | 빈도 |
|-----------|------|------|
| 인텔 토론 2회/일 | 현재 1회 → 오전/오후 2회 | +1회/일 |
| 코드 리뷰 자동화 | git push 때마다 Codex 코드 리뷰 | 새로 추가 |
| 경쟁사 분석 루프 | 쿠팡 경쟁 셀러 모니터링+분석 | 주 2회 |
| 아이디어 실험실 확장 | 시간당 → 30분마다 | 2배 빈도 |
| 심층 트렌드 리포트 | 일일 요약 → 일일 분석 리포트 | 강화 |
| 자동 SEO A/B 테스트 | 상품 제목 변형 → 성과 추적 | 새로 추가 |

## 구현 순서

### Week 1: n8n 기본 워크플로우
1. n8n에 Telegram 봇 연결 (@Selpix_wol_bot 또는 별도)
2. git backup 워크플로우 2개 (vault + config)
3. PC WoL/shutdown 워크플로우
4. OpenClaw에서 해당 크론잡 비활성화

### Week 2: n8n 확장 + Ollama
1. 모니터링 워크플로우 (health check, price monitor 등)
2. Ollama 연동 테스트 (n8n → Ollama Chat Model 노드)
3. 트윗 분류 워크플로우 (n8n → Ollama → Telegram)

### Week 3: Codex 집중 투입
1. intel-discussion-loop 2회/일로 확장
2. 코드 리뷰 자동화 워크플로우 추가
3. 토큰 사용률 모니터링 + 조정

### Week 4: 최적화
1. n8n ↔ OpenClaw 연동 (webhook으로 판단 필요한 건 OpenClaw에 전달)
2. Ollama fallback 로직 (PC 오프라인 시 Codex fallback)
3. 전체 비용/효율 리포트
