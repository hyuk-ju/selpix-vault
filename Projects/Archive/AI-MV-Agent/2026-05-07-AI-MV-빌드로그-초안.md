## 빌드로그 아웃라인

### Problem

뮤직비디오 AI 도구가 쉽게 빠지는 함정은 “AI가 완성본을 자동으로 만든다”는 과장이다. 실제 편집자의 병목은 최종 판단을 대체하는 것이 아니라, 많은 테이크와 레퍼런스 속에서 쓸만한 후보를 빠르게 찾고 타임라인으로 넘기는 과정이다.

### What changed

최근 변경은 기능 추가보다 공개 포지셔닝 정렬에 가깝다. 한국어 공개 소개 문서가 기술형 크리에이터/개발자를 명확히 겨냥하고, no-media demo와 FCPXML output을 제품의 첫 신뢰 지점으로 세웠다. 즉, MV BRAIN은 “자동 MV 생성기”가 아니라 inspect 가능한 local-first 편집 어시스턴트로 설명된다.

### Technical detail

개발자에게 보여줄 핵심은 재현 가능한 입출력 경계다.

1. `mv-brain demo`는 개인 촬영본, Qdrant server, provider key 없이 데모 프로젝트와 샘플 FCPXML output을 만든다.
2. `mv-brain serve`는 local FastAPI + React UI로 clip browser, 설정, output 다운로드 흐름을 보여준다.
3. README의 장기 구조는 `visual`, `audio`, `style` 3-channel embedding을 전제로 하며, 검색 결과가 채팅 응답에서 끝나지 않고 Final Cut Pro handoff로 이어진다.

### Demo angle

60~90초 데모 구성:

1. 터미널에서 `mv-brain demo` 실행 경로와 생성 파일을 보여준다.
2. 로컬 UI에서 `Demo Project`, `8 demo clips`, output 패널의 `demo_roughcut.fcpxml`을 보여준다.
3. 한 문장으로 포지셔닝을 고정한다: “AI가 편집을 끝내는 게 아니라, 편집자가 고를 후보를 찾고 FCPXML로 넘긴다.”

### Next experiment

다음 실험은 실제 기능 추가가 아니라 공개 데모 패키징이다. `docs/public/overview.ko.md`와 README 기준으로 3장짜리 스크린샷 세트—Demo Project, 자연어 검색/FX 추천, FCPXML output—를 만들고, GitHub README 상단에 들어갈 짧은 GIF 또는 이미지 흐름으로 압축한다.
