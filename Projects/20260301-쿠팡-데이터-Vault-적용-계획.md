## 2. Vault 적용 전략

### 원칙
- 엑셀 원본은 건드리지 않는다
- Markdown 변환본을 Vault에 넣어 RAG가 인덱싱하게 한다
- 사람이 읽기 쉽고, AI가 검색하기 좋은 형태로 구조화한다

### 생성할 파일 구조

```
Finance/
├── 20260301-쿠팡-매출-일별-요약.md        ← 일별 매출 트렌드
├── 20260301-쿠팡-월별-매출-분석.md        ← 월별 집계 + 성장률
└── 20260301-쿠팡-광고비-대비-ROAS-분석.md  ← 광고 투자 대비 수익

Products/
├── 20260301-쿠팡-상품별-실적-총괄.md      ← 130개 상품 성과 요약
├── 20260301-쿠팡-카테고리별-실적.md       ← 14개 카테고리 비교
└── 20260301-쿠팡-취소율-분석.md          ← 취소/반품 패턴

Research/쿠팡트렌드/
└── 20260301-쿠팡-1년-데이터-인사이트.md    ← 전체 기간 핵심 발견
```

## 4. 데이터 정제 이슈

| 문제 | 원인 | 해결 방법 |
|------|------|----------|
| 구매전환율 컬럼 타입 오류 | 문자열(%)이 연결되어 하나의 셀에 들어감 | 파싱 시 % 제거 후 float 변환 |
| 날짜 컬럼 혼합 타입 | 일부 NaN 또는 float 섞임 | dropna() + astype(str) 후 파싱 |
| 광고 데이터 5개 파일 분리 | 쿠팡이 기간/캠페인별로 나눠서 다운로드 | concat 후 중복 제거 |
| 취소 관련 컬럼명 불확실 | 실제 컬럼명 확인 필요 | 실행 시 columns 재확인 |

## 5. 실행 순서

```
Step 1: 엑셀 → Python 정제 (데이터 클리닝 + 집계)
Step 2: 집계 결과 → 7개 Markdown 파일 자동 생성
Step 3: Vault 해당 폴더에 저장
Step 4: RAG 인덱서 실행 (--incremental)
Step 5: 검색 테스트 ("수영가방 매출", "광고 ROAS", "월별 성장률")
```

### Step 1 상세: Python 변환 스크립트

하나의 스크립트(`scripts/coupang_data_to_vault.py`)로 7개 엑셀을 읽어서 7개 마크다운 파일을 생성한다.

**입력**: `/home/dev/openclaw/data/coupang-exports/` (엑셀 파일 저장 위치)
**출력**: Vault 각 폴더에 직접 마크다운 생성

### 자동화 (향후)

- 쿠팡 Wing에서 월 1회 엑셀 다운로드 → 지정 폴더에 넣기
- OpenClaw 크론이 감지 → 변환 스크립트 실행 → Vault 업데이트
- RAG 인덱서가 2시간마다 자동 인덱싱
