# 쿠팡 파이프라인 리팩토링 리뷰 (트렌드 주도형 개편)

## 📌 작업 배경
기존의 소싱 파이프라인은 정교하지 못한 **"AI 트위터 뉴스 연동"** 기능으로 인해, 실제 이커머스 트렌드와 무관한 키워드(예: OpenAI 릴리즈, LLM 모델 이름 등)가 도매꾹 소싱 키워드로 투입되는 심각한 결함이 있었습니다.
전환율이 극도로 낮은 묻지마 소싱을 방지하고자, 에이전트 간 토론 레이어를 거쳐 **트렌드 지시서(Sourcing Directive) 기반의 파이프라인**으로 성공적으로 아키텍처를 개편했습니다.

## 🛠 주요 변경 사항
1. **아키텍처 대수술 (Architecture Shift)**
   - `trend-scout` 에이전트 전용 일일 크론(`coupang-daily-trend`)을 신설했습니다.
   - 기존의 호스트 기반 네이버 트렌드 API 크롤러(`trend_aggregator.py`)가 만들어낸 `candidate_keywords.json`을 `trend-scout`이 먼저 읽고 분석합니다.
   - 최종적으로 파이프라인(`pipeline_sourcing.js`)은 스스로 키워드를 무작위 수집하지 않고, 오직 `trend-scout`이 남긴 `sourcing_directive.json`만 바라보고 타겟 소싱을 집행합니다.

2. **레거시 의존성 완전 제거 (Dead Code Removal)**
   - `pipeline_sourcing.js` 내에 잔존하던 쓸데없는 트위터 수집 연동 로직 (`loadTwitterKeywords`)과, 파편화된 무의미한 키워드 병합 코드를 싹 날려버렸습니다.
   - 스크립트의 코드 라인이 가벼워졌으며 비즈니스 로직(마진 계산, 중복 체크 등)만 남겨 유지보수성이 극대화되었습니다.

3. **안전 장치 유지 및 강화 (Safety Guards Maintained)**
   - 개편 과정에서 잘려나갈 뻔했던 **블랙리스트 필터** 및 **7일 이내 중복 소싱 방지 헬퍼 함수 (`isRecentlySourced`)**를 복원/최적화하여 메인 파이프라인 흐름에 다시 안전하게 꽂아넣었습니다.
