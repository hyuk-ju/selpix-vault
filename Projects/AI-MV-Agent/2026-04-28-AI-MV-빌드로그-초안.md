## 빌드로그 아웃라인

### Problem

뮤직비디오 편집자는 촬영본이 늘어날수록 “쓸만한 컷을 찾는 시간”에 병목이 생긴다. 완전 자동 MV 생성보다 먼저 필요한 것은, 편집자가 로컬 footage를 유지한 채 후렴용 댄스 컷·BV 클로즈업·전환이 쉬운 브리지 컷을 빠르게 찾는 보조 도구다.

### What changed

MV BRAIN의 현재 MVP는 “source-first editing brain” 쪽으로 정리되어 있다. CLI와 로컬 웹 UI가 같은 제품 스토리를 공유하고, 검색·FX 추천·FCPXML rough-cut export를 Final Cut Pro workflow로 연결하는 방향이다. 오늘 빌드로그는 실제 영상/API 없이도 이해 가능한 no-media smoke demo 섹션을 README에 추가하는 것을 다음 작은 작업으로 잡는다.

### Technical detail

핵심 기술 포인트는 clip memory를 `visual`, `audio`, `style` 3개 채널로 분리하는 구조다. README 기준으로 `clip_archive`, `mv_refs`, `brain_refs` 컬렉션을 역할별로 나누고, 검색 CLI는 `--channel visual|audio|style` 방식으로 질의 의도를 좁힐 수 있다. 이 구조는 “무엇이 보이는가”, “음악/에너지상 어디에 맞는가”, “편집상 쓸만한가”를 분리해서 설명하기 좋다.

### Demo angle

실제 개인 영상이나 API 키를 공개하지 않고도, 개발자에게는 아래 흐름을 보여주는 것이 좋다.

1. 샘플/fixture 메타데이터로 클립 후보가 이미 인덱싱된 상태를 가정한다.
2. `mv-brain search "후렴 고에너지 댄스 컷" --channel audio` 같은 질의를 보여준다.
3. 선택 클립으로 `roughcut.fcpxml`이 만들어지고 Final Cut Pro timeline으로 넘어가는 화면/파일 예시를 보여준다.
