## 남은 개선 사항

### 1. 가드레일 명문화 (난이도: 낮음) ✅ 완료

AGENTS.md에 규칙 3개를 텍스트로 추가하는 작업. 코드 수정 없음.

| 가드레일 | 내용 | 추가 위치 |
|----------|------|-----------|
| Guard 1 | critic "반대" 시 사용자 HITL 승인 없이 적용 금지 | AGENTS.md 토론 규칙 |
| Guard 3 | vault에 ADR/Spec 없는 합의는 무효 | AGENTS.md 일반 규칙 |

### 2. intel-discussion-loop에도 ADR 출력 적용 (난이도: 중간)

현재 인텔 토론(`intel-discussion-loop` 크론)은 자유 형식으로 결과를 냄. 여기도 ADR 포맷을 적용하면 인텔 결정도 기록에 남음.

- `build_intel_briefing.js` → 토론 프롬프트에 5필드 출력 강제
- `apply_intel.js` → 적용 전 ADR 노트 존재 여부 검증

### 3. Runbook 첫 문서 작성 (난이도: 낮음)

vault/Runbooks/가 비어있으니, 자주 발생하는 장애 1~2개를 Runbook으로 정리.

후보:
- **쿠팡 등록 연속 실패** — 에러 코드별 대응 절차
- **텔레그램 fetch 실패** — 재시도 로직, 수동 확인 방법
- **크론잡 미실행** — systemd 상태 확인, 로그 위치

### 4. pipeline_health_check → Runbook 연동 (난이도: 중간)

장애 감지 시 관련 Runbook을 자동으로 참조/링크하는 기능.

- `pipeline_health_check.js`에서 에러 패턴별 Runbook 매칭
- 텔레그램 알림에 "📖 참고: [[Runbooks/쿠팡-등록-실패]]" 링크 추가

### 5. 실제 운영 검증 (난이도: 없음, 기다리기만)

다음 daily-briefing(09:00 KST)에서:
- 아이디어 추출 → save_idea.js 호출 확인
- 승인 버튼 → 4단계 토론 → ADR 자동 생성 확인
